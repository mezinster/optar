# Сканы со слишком низким разрешением: медленный метод { #scans-that-are-too-coarse-the-slower-reader }

Начиная с 0.4.0, в программе есть второй, более медленный метод чтения для
сканов, сделанных со слишком низким для их размера точек разрешением,
например для страницы со стандартными точками, отсканированной при 300 dpi
вместо 600.

Если можете, сканируйте с рекомендованным разрешением. Медленный метод
восстанавливает некоторые сканы с низким разрешением, но не все (см.
[«Что показано, а что нет»](evidence.md#the-slower-reader)).

## Когда он работает { #when-it-runs }

Он запускается сам, в двух случаях:

- Обычный метод чтения не может опознать скан, но находит на нём контур
  страницы.
- На скане с низким разрешением (меньше 2,5 пикселя скана на точку) обычный
  метод нашёл только надпись без метки и не нашёл заголовка, а данные
  страницы прочитались плохо (1% или больше её символов не поддаётся
  коррекции). На таком скане надпись может читаться там, где данные не
  читаются.

Страница, данные которой читаются хорошо, — это старая страница без
заголовка, и её не трогают. Если медленный метод ничего не находит,
остаётся то, что прочитано по надписи.

## Как он работает { #how-it-works }

Медленный метод увеличивает скан. По точкам, в которых обычный метод уверен,
он узнаёт, как соседние точки расплываются и сливаются друг с другом в каждой части
страницы. Затем он читает каждую точку с учётом этого и выбирает каждый
символ целиком.

## В приложении { #in-the-application }

![Две страницы, прочитанные медленным методом, с выделенными скорректированными точками](img/slow-pages.png)

*Сгенерированная тестовая страница, маленькая и отсканированная с очень
низким разрешением. Скорректированные точки выделены на просмотре.*

- Пока он работает, в строке скана видны этап медленного метода и ход
  работы. Если выбрать строку, в подробностях будет сказано, что это
  занимает около минуты.
- Потом в строке сказано, что страница прочитана медленным методом и сколько
  точек он скорректировал, например: «Страница 3 · Прочитана медленным
  методом · скорректировано 265 112 точек». Скорректированная точка — это
  точка, собственное изображение которой на скане разошлось с решением,
  принятым для всего её символа.
- Скорректированные точки выделены на просмотре скана, каждое выделение
  шириной в одну точку. На сканах с низким разрешением это часто несколько
  процентов точек, поэтому, если смотреть на страницу целиком, она выглядит
  окрашенной — тем плотнее, чем больше коррекций. При увеличении видны
  отдельные точки.
- Когда документ проверен, в строке добавляется, сколько байт страницы
  исправила защита документа («· исправлено 6 912 байт защитой документа»).
  Если выбрать страницу, видны оба числа.

Такая страница никогда не называется «В порядке» и считается отдельно в
строке внизу. Медленный метод даёт каждому символу самое вероятное значение,
поэтому он не может сказать, что на странице не поддаётся исправлению.

## В командной строке { #on-the-command-line }

`optar decode` тоже запускает его сам и сообщает об этом в stderr для каждого
скана, к которому он применяется. `--no-slow-reader` его отключает.

## Сколько это занимает { #how-long-it-takes }

На машине разработчика на страницу A4 ушло в целом от 40 до 70 секунд: от 20
до 35 секунд, пока обычный метод не сдался, и затем от 20 до 35 секунд на
медленный метод.

Изображение, которое вовсе не является страницей optar, но в котором найден
контур страницы, обрабатывается примерно на 20–35 секунд дольше, чем без
медленного метода.

## Ограничения { #limits }

- Он опознаёт страницу только по заголовку в её данных. Старые страницы в
  стиле 0.2, которые опознаются по метке в надписи, он не охватывает.
- Страница, метку которой принял обычный метод, никогда не передаётся
  медленному методу.
- Ожидается, что стандартной защиты не хватит для страницы со стандартными
  точками, отсканированной примерно при 290 dpi. Единственный реальный
  документ, восстановленный таким образом, был с высокой защитой, и ему
  понадобилось больше исправлений, чем может дать стандартная защита.
- Он не выдаёт неверный файл за верный: как всегда, проверенным файл делает
  только отпечаток.
