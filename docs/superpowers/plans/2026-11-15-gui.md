# Optar GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cross-platform desktop application, `optar-gui`, mostly for reading scans back into a file with per-page health, plus the library features it needs: reading the printed label, identifying a scan, a document tag, and per-bit decode detail.

**Architecture:** New library modules under `src/optar` (no Qt) do label reading, scan identification, the tag and decode detail. A new package `src/optar_gui` holds the application: `document.py` contains every rule about which scan is which page and what the document's state is, in plain Python; `work.py` and `jobs.py` run library calls in the background; the widgets only display the document and forward actions.

**Tech Stack:** Python 3.10+, numpy, Pillow, PySide6 (Qt 6), pytest, pytest-qt, ruff, PyInstaller, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-15-gui-design.md`. Read it before starting any task.

## Global Constraints

- Nothing under `src/optar` may import Qt or `optar_gui`. The library's runtime dependencies stay numpy and Pillow.
- PySide6 is an optional extra: `pip install 'optar[gui]'`. The default `pytest` run and the existing CI jobs must pass without PySide6 installed.
- `src/optar_gui/document.py`, `work.py` and `text.py` must not import Qt.
- Widgets contain no rules. Anything that decides placement, health or state lives in `document.py`.
- No library call that reads or decodes a scan may run on the interface thread.
- The decoder's algorithm and constants are not retuned. The C sources, `Makefile` and `pgm2ps` are not edited.
- Format numbers live only in `src/optar/format.py`.
- Every new `.py` file starts with `# (c) GPL 2007 Karel 'Clock' Kulhavy, Twibright Labs; Python port 2026`.
- Tests write only under pytest's `tmp_path`.
- The page data, format string, error correction and bit layout do not change. Pages encoded with the same label stay byte-identical to the C encoder's.
- The window supports only the `a4` and `letter` presets.
- Commit subjects are capitalised, third-person present, no prefix. Work on branch `gui`. Do not push or open a pull request without the owner saying so.

**Reference values**

| | A4 | US Letter |
|---|---|---|
| format string | `0-65-93-24-3-1-2-24` | `0-67-87-24-3-1-2-24` |
| page pixels (W x H) | 1546 x 2242 | 1594 x 2098 |
| outline width / height | 0.6896 | 0.7598 |
| payload bytes per page | 199,773 | 192,591 |
| label characters that print | 98 | 101 |
| logo width at the left of the label | 265 px | 265 px |

Tag: `[SIZE:FINGERPRINT]`, SIZE decimal bytes, FINGERPRINT the first 8 hex digits (lower case) of SHA-256. Label free text: `[2481152:3f9a2c1b] holiday-photos.tar`.

Rotation convention everywhere: `rotation` is the number of counter-clockwise quarter turns that make a scan upright: `upright = np.rot90(image, rotation)`.

## Review Focus

1. **Something that is not an optar page is added** (a photo, a text file renamed `.png`, a PDF): it appears as Not readable with a reason, nothing crashes, and the rest of the window keeps working. (Tasks 6, 9, 10)
2. **The same file is added twice**: it is listed once; it does not become its own spare. (Task 7)
3. **The window is closed, or a scan removed, while pages are still being processed**: work stops, no error dialog appears, the process exits. (Tasks 9, 10)
4. **One character of a tag is misread on one page**: that scan shows under "Not part of this file"; assigning it by hand puts it in the document, and the fingerprint check then gives the verdict. (Tasks 7, 8, 12)
5. **Saving fails** (read-only folder, existing read-only file): an error is shown, an existing file is untouched, and the document stays as it was. (Task 10)

## Parallel lanes

Tasks 1 to 8 form three independent lanes that touch different files: **A** = 1, 2, 3; **B** = 4, 5, 6; **C** = 7, 8. Task 9 needs all three. Tasks 10, 11 and 12 all edit `read_tab.py` and run in order. Task 13 needs Task 10 and can run beside 11 and 12. Task 14 needs 13; Task 15 can run beside 14.

def test_read_scan_is_safe_from_many_threads(tmp_path):
    import threading
    from PIL import Image
    from optar.imageio import read_scan
    arr = np.full((300, 200), 255, np.uint8)
    paths = []
    for i in range(8):
        p = tmp_path / f"s{i}.png"; Image.fromarray(arr).save(p); paths.append(p)
    before = Image.MAX_IMAGE_PIXELS
    seen, errors = [], []
    def worker(p):
        try:
            for _ in range(20):
                read_scan(p); seen.append(Image.MAX_IMAGE_PIXELS)
        except Exception as e:  # noqa: BLE001
            errors.append(e)
    ts = [threading.Thread(target=worker, args=(p,)) for p in paths]
    [t.start() for t in ts]; [t.join() for t in ts]
    assert not errors and Image.MAX_IMAGE_PIXELS == before

### Task 2: Document tag

**Files:**
- Create: `src/optar/tag.py`, `tests/unit/test_tag.py`

**Interfaces:**
- Produces:
  - `FINGERPRINT_DIGITS = 8`.
  - `Tag` (frozen dataclass): `size: int`, `fingerprint: str`; property `text -> str` (`"[2481152:3f9a2c1b]"`); `fits(total: int, fmt: PageFormat) -> bool` (true when `(pages - 1) * B < size <= pages * B` with `B = fmt.net_bits // 8` and `pages = max(total, 1)`, and also when `size == 0` and `total == 0`); `matches(data: bytes) -> bool` (`len(data) == size` and the fingerprint of `data` equals `fingerprint`).

  - `split_label(text: str) -> tuple[Tag | None, str]`: a leading `[digits:8 lower-case hex]` followed by end of text or one space is a tag; otherwise `(None, text)`.

import hashlib
from optar.format import PageFormat
from optar.tag import Tag, make_tag, split_label, tagged_label

A4 = PageFormat(65, 93)

def test_make_tag_and_text():
    data = b"hello world"
    t = make_tag(data)
    assert t == Tag(11, hashlib.sha256(data).hexdigest()[:8])
    assert t.text == f"[11:{t.fingerprint}]" and t.matches(data)
    assert not t.matches(data + b"\0") and not t.matches(b"hello_world")

def test_tagged_label_and_split_round_trip():
    t = Tag(2481152, "3f9a2c1b")
    assert tagged_label(t, "holiday-photos.tar") == "[2481152:3f9a2c1b] holiday-photos.tar"
    assert tagged_label(t, "") == "[2481152:3f9a2c1b]"
    assert split_label("[2481152:3f9a2c1b] holiday photos.tar") == (t, "holiday photos.tar")
    assert split_label("[2481152:3f9a2c1b]") == (t, "")

def test_split_label_rejects_near_misses():
    for text in ["plain.tar", "[12:3F9A2C1B] x", "[12:3f9a2c1] x", "[12:3f9a2c1bb] x",
                 " [12:3f9a2c1b] x", "[12:3f9a2c1b]x", "[:3f9a2c1b] x", "[12-3f9a2c1b] x", ""]:
        assert split_label(text) == (None, text)

def test_fits_page_count():
    b = A4.net_bits // 8                      # 199773
    assert Tag(1, "0" * 8).fits(1, A4) and Tag(b, "0" * 8).fits(1, A4)
    assert not Tag(b + 1, "0" * 8).fits(1, A4) and Tag(b + 1, "0" * 8).fits(2, A4)
    assert not Tag(b, "0" * 8).fits(2, A4)
    # an empty file prints one page labelled 1/0
    assert Tag(0, "0" * 8).fits(0, A4)
    assert not Tag(5, "0" * 8).fits(0, A4)

### Task 4: Page grid and decode detail

**Files:**
- Modify: `src/optar/decoder/__init__.py`, `src/optar/__init__.py`
- Create: `tests/unit/test_decode_detail.py`

**Interfaces:**
- Consumes: the existing pipeline stages and `sample._bit_coord`.
- Produces (all in `optar.decoder`, exported from `optar`):
  - `PageGrid` (frozen dataclass): `fmt: PageFormat`, `options: DecodeOptions`, `cleaned: np.ndarray` (the scan after dirt removal), `levels: Levels`, `geometry: Geometry`, `positions: np.ndarray`, `cutlevels: np.ndarray`.
  - `locate_page(image, fmt, options=None) -> PageGrid`: the first half of today's `decode_page` (checks, levels, dirt, corners, geometry, crosses), raising the same `DecodeError`s.
  - `decode_located(grid: PageGrid, *, debug: bool = False, detail: bool = False) -> PageResult`: the second half.
  - `decode_page(image, fmt, options=None, *, debug=False, detail=False)` becomes `decode_located(locate_page(...), ...)`. Its results for `detail=False` are unchanged.
  - `PageResult` gains three fields, all `None` unless `detail=True`: `corrected_bits: np.ndarray | None` (int64 channel positions, ascending, of every bit error correction changed), `lost_symbols: np.ndarray | None` (int64 indices of unrecoverable symbols), `grid: PageGrid | None`.
  - `page_to_scan(grid: PageGrid, x, y) -> tuple[np.ndarray, np.ndarray]`: page coordinates (as `layout.channel_xy`: relative to the top-left cross, may lie outside the cross grid) to scan pixel-centre coordinates.

Corrected bits are found without touching `fec.py`: for symbols with `errors >= 0`, XOR the received codeword with `encode_symbols(words, fmt)`; bit `b` (0 = most significant) of symbol `s` is channel position `s + b * fmt.fec_syms`.

import numpy as np, pytest
from optar import PageFormat, decode_page, encode
from optar.decoder import decode_located, locate_page, page_to_scan
from optar.layout import channel_xy
from tests.helpers import fake_scan, seeded_bytes

F = PageFormat(65, 93)

@pytest.fixture(scope="module")
def page():
    return next(encode(seeded_bytes(21, 150000), F)).pixels

def flipped_scan(page, positions):
    x, y = channel_xy(F)
    p = page.copy()
    p[y[positions] + F.border, x[positions] + F.border] ^= 255
    return fake_scan(p, scale=1, margin=40)

def test_detail_reports_exactly_the_flipped_bits(page):
    rng = np.random.default_rng(5)
    pos = np.sort(rng.choice(F.used_bits, 150, replace=False))
    r = decode_page(flipped_scan(page, pos), F, detail=True)
    assert r.stats.uncorrectable == 0
    assert np.array_equal(r.corrected_bits, pos) and r.corrected_bits.dtype == np.int64
    assert len(r.lost_symbols) == 0 and r.grid is not None

def test_detail_reports_lost_symbols(page):
    s = 777
    pos = s + np.arange(4) * F.fec_syms            # four wrong bits in one Golay symbol:
    r = decode_page(flipped_scan(page, pos), F, detail=True)   # always detected, never corrected
    assert r.stats.uncorrectable == 1
    assert r.lost_symbols.tolist() == [s] and len(r.corrected_bits) == 0

def test_default_result_is_unchanged(page):
    scan = fake_scan(page, scale=1, margin=40)
    a, b = decode_page(scan, F), decode_page(scan, F, detail=True)
    assert a.corrected_bits is None and a.lost_symbols is None and a.grid is None
    assert np.array_equal(a.bits, b.bits) and a.stats == b.stats

def test_locate_then_decode_equals_decode_page(page):
    scan = fake_scan(page, scale=3, margin=60)
    grid = locate_page(scan, F)
    assert np.array_equal(decode_located(grid).bits, decode_page(scan, F).bits)

def test_page_to_scan_maps_data_pixels(page):
    grid = locate_page(fake_scan(page, scale=3, margin=60), F)
    sx, sy = page_to_scan(grid, np.array([0, 10]), np.array([0, 20]))
    # page pixel (x, y) is at scan (60 + 3*(border + x) + 1, 60 + 3*(border + y) + 1)
    assert sx == pytest.approx([60 + 3 * 2 + 1, 60 + 3 * 12 + 1], abs=0.3)
    assert sy == pytest.approx([60 + 3 * 2 + 1, 60 + 3 * 22 + 1], abs=0.3)

### Task 5: Reading the printed label

**Files:**
- Create: `src/optar/label.py`, `tests/unit/test_label.py`
- Modify: `src/optar/__init__.py`

**Interfaces:**
- Consumes: `PageGrid`, `page_to_scan`, `crosses.interp`, `font.glyph_strip`, `font.FIRST_CHAR`, `font.GLYPH_CELLS`, `TEXT_WIDTH`.
- Produces:
  - `label_capacity(fmt: PageFormat) -> int`: characters that print: `(fmt.data_width - logo_width) // TEXT_WIDTH` with `logo_width = glyph_strip().shape[1] - TEXT_WIDTH * GLYPH_CELLS` (98 for A4, 101 for Letter).
  - `printed_label(fmt: PageFormat, text: str) -> str`: what the encoder actually prints for `font.label_text(...)` output: characters outside codes 32..126 removed, cut to `label_capacity(fmt)`, trailing spaces removed.
  - `LabelReading` (frozen): `text: str` (trailing spaces removed), `confidence: float` (the lowest best-match score over all character cells, 0..1).
  - `read_label(grid: PageGrid) -> LabelReading`: sample the label band (page rows `data_height .. data_height + text_height - 1`, columns `0 .. data_width - 1`) through `page_to_scan` and `interp` on `grid.cleaned`; a sample is white when above the midpoint between the band's darkest and brightest samples; skip the logo; for each 13-pixel cell choose the glyph with the highest fraction of agreeing pixels.
  - `LabelInfo` (frozen): `format: str`, `page: int`, `total: int`, `text: str` (the free text after the page numbers, possibly empty).
  - `parse_label(text: str) -> LabelInfo | None`: matches optional leading spaces, the eight-number format string, a space, `page/total`, then end of text or a space and the free text.
  - `MIN_LABEL_CONFIDENCE: float`: the acceptance threshold. Choose it from the tests below: every degraded case must clear it and the non-label cases must not. Record the observed scores in the commit message.

def test_capacity():

- Two identified scans belong to the same group when format and total are equal and either both have equal tags, or neither has a tag and one name is a prefix of the other (trailing spaces ignored). A tagged and an untagged scan are never in the same group.

- Within a page, the scan in use is the one chosen by `use_scan`; otherwise the one with the best outcome (fewest `lost`, then fewest `repaired`, then earliest added); scans with no outcome yet rank last.
- A scan whose page number is outside `1..max(total, 1)` is unreadable with reason `"page number out of range"`.
