# Сканы з занадта нізкай раздзяляльнасцю: павольны метад чытання { #scans-that-are-too-coarse-the-slower-reader }

Пачынаючы з версіі 0.4.0 у праграмы ёсць другі, больш павольны метад чытання
для сканаў, зробленых з занадта нізкай для іх памеру кропак раздзяляльнасцю,
напрыклад старонкі са стандартнымі кропкамі, адсканаванай пры 300 dpi замест
600.

Калі можаце, скануйце з рэкамендаванай раздзяляльнасцю. Павольны метад
аднаўляе некаторыя сканы з нізкай раздзяляльнасцю, але не ўсе (глядзіце
[«Што паказана, а што не»](evidence.md#the-slower-reader)).

## Калі ён запускаецца { #when-it-runs }

Ён запускаецца сам, у двух выпадках:

- Звычайны метад чытання не можа апазнаць скан, але знаходзіць на ім контур
  старонкі.
- Скан з нізкай раздзяляльнасцю (менш за 2,5 пікселя скана на кропку) даў
  звычайнаму метаду толькі надпіс без пазнакі і ніякага загалоўка, а даныя
  старонкі прачыталіся дрэнна (1% або больш яе сімвалаў невыпраўныя). На
  такім скане надпіс яшчэ можа быць чытэльным там, дзе даныя ўжо не
  чытаюцца.

Старонка, даныя якой чытаюцца добра, — гэта старая старонка без загалоўка, і
яе не чапаюць. Калі павольны метад нічога не знаходзіць, застаецца тое, што
было прачытана з надпісу.

## Як ён працуе { #how-it-works }

Павольны метад павялічвае скан. Па тых кропках, у якіх звычайны метад
упэўнены, ён вывучае, як суседнія кропкі расплываюцца адна ў адну ў кожнай
частцы старонкі. Потым ён чытае кожную кропку з улікам гэтага і выбірае
кожны сімвал цалкам.

## У праграме { #in-the-application }

![Дзве старонкі, прачытаныя павольным метадам, са скарэкціраванымі кропкамі, вылучанымі на праглядзе](img/slow-pages.png)

*Згенераваная тэставая старонка, маленькая і адсканаваная з вельмі нізкай
раздзяляльнасцю. Скарэкціраваныя кропкі вылучаны на праглядзе.*

- Пакуль ён працуе, у радку скана паказваюцца этап павольнага метаду і ход
  выканання. Калі выбраць радок, у падрабязнасцях будзе сказана, што гэта
  зойме каля хвіліны.
- Потым радок паведамляе, што старонка прачытана павольным метадам і колькі
  кропак ён скарэкціраваў, напрыклад: «Старонка 3 · Прачытана павольным
  метадам · скарэкціравана 265 112 кропак». Скарэкціраваная кропка — гэта
  кропка, уласны след якой на скане разышоўся з рашэннем, прынятым для яе
  сімвала.
- Скарэкціраваныя кропкі вылучаны на праглядзе скана, і кожнае вылучэнне
  шырынёй у адну кропку. На сканах з нізкай раздзяляльнасцю гэта часта
  некалькі працэнтаў кропак, таму, калі глядзець на старонку цалкам, яна
  мае адценне, гэтак жа шчыльнае, як і карэкцыі. Пры павелічэнні відаць
  асобныя кропкі.
- Калі дакумент прайшоў праверку, радок дадае, колькі байтаў старонкі
  выправіла абарона дакумента («· выпраўлена 6 912 байтаў абаронай
  дакумента»). Калі выбраць старонку, паказваюцца абедзве лічбы.

Такая старонка ніколі не атрымлівае стан «У парадку» і ў радку ўнізе
лічыцца асобна. Павольны метад дае кожнаму сімвалу сваю найлепшую здагадку,
таму ён не можа сказаць, што на старонцы выправіць нельга.

## У камандным радку { #on-the-command-line }

`optar decode` таксама запускае яго сам і паведамляе пра гэта ў stderr для
кожнага скана, на якім яго спрабуюць. `--no-slow-reader` адключае яго.

## Колькі гэта займае { #how-long-it-takes }

Чытанне старонкі A4 на камп'ютары распрацоўшчыка заняло агулам ад 40 да 70 секунд:
ад 20 да 35 секунд, пакуль звычайны метад не здасца, і потым ад 20 да 35
секунд на павольны метад.

На выяву, якая зусім не з'яўляецца старонкай optar, але на якой знаходзіцца
контур старонкі, ідзе прыкладна на 20–35 секунд больш, чым без павольнага
метаду.

## Абмежаванні { #limits }

- Ён апазнае старонку толькі па загалоўку ў яе даных. Старыя старонкі
  ў стылі 0.2, якія апазнаюцца па пазнацы ў надпісе, ён не ахоплівае.
- Старонка, пазнаку якой прыняў звычайны метад, ніколі не перадаецца
  павольнаму метаду.
- Чакаецца, што стандартнай абароны не хопіць для старонкі са стандартнымі
  кропкамі, адсканаванай прыкладна пры 290 dpi. Адзіны рэальны дакумент,
  які ўдалося аднавіць такім чынам, меў высокую абарону, і яму спатрэбілася
  больш выпраўленняў, чым можа даць стандартная абарона.
- Ён не робіць няправільны файл падобным на правільны: як заўсёды,
  правераным файл робіць толькі адбітак.
