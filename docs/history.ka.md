# ისტორია { #history }

optar 2007 წელს C ენაზე დაწერა კარელ „Clock“ კულჰავიმ (Twibright Labs),
როგორც პროგრამები `optar`, `unoptar` და `pgm2ps`. მისი ვებგვერდია
[ronja.twibright.com/optar](http://ronja.twibright.com/optar/). 2012 წლიდან
2018 წლამდე კოლინ დინი საწყის კოდს ხელმისაწვდომს ინახავდა და აუმჯობესებდა
მისამართზე [github.com/colindean/optar](https://github.com/colindean/optar).

ეს პროექტი სწორედ ამ საწყისი კოდიდან დაიწყო. თავდაპირველი C პროგრამები
უცვლელად ინახება რეპოზიტორიის საქაღალდეში `lega-c`. ისინი ისტორიაა: ამ
პროექტში მათ აღარაფერი აგებს და აღარაფერი უშვებს.
[README](https://github.com/mezinster/optar#history-the-original-c-program)
ინახავს მათ თავდაპირველ ინსტრუქციებს.
