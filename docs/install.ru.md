# Установка { #install }

## Загрузка { #download }

Скачайте файл для своей системы из
[раздела Releases на GitHub](https://github.com/mezinster/optar/releases/latest).
`<tag>` ниже — это номер версии, например `v0.5.0`.

| Система | Настольное приложение | Командная строка |
|---|---|---|
| Linux | `optar-gui-<tag>-linux-x86_64` | `optar-<tag>-linux-x86_64` |
| macOS (Apple silicon) | `optar-gui-<tag>-macos-arm64.zip` | `optar-<tag>-macos-arm64` |
| Windows | `optar-gui-<tag>-windows-x86_64.exe` | `optar-<tag>-windows-x86_64.exe` |

Каждая программа — это один файл, и больше ничего устанавливать не нужно.

- **Linux:** сначала выполните для файла `chmod +x`.
- **macOS:** выполните `chmod +x` для программы командной строки. Распакуйте
  приложение и попробуйте его открыть. Программы не подписаны, поэтому macOS
  может отказаться их открывать: откройте «Системные настройки», раздел
  «Конфиденциальность и безопасность», и нажмите «Всё равно открыть» (в более
  старых версиях macOS щёлкните приложение правой кнопкой мыши и выберите
  «Открыть»).
- **Windows:** программы не подписаны, поэтому при первом запуске Windows
  может показать предупреждение.

## Из исходного кода { #from-source }

Нужен Python 3.12 или новее и копия репозитория.

Программа командной строки (устанавливает numpy и Pillow):

    pip install .

Вместе с настольным приложением:

    pip install '.[gui]'
    optar-gui

## Убедиться, что всё работает { #check-that-it-works }

`optar --version` и `optar-gui --version` выводят номер версии.

`optar-gui --self-test` запускает приложение без экрана и убеждается, что оно
умеет кодировать и читать страницы.
