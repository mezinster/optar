# Получить файл обратно { #read-it-back }

## Сканирование { #scanning }

- Сканируйте в оттенках серого (256 уровней) или в цвете. Не сканируйте в
  чёрно-белом режиме.
- Отключите любой режим «документ» и любую очистку текста. Они делают точки
  чёрными или белыми ещё до того, как их увидит программа.
- Выбирайте разрешение по размеру точек: 600 dpi для стандартных точек, причём
  1200 dpi немного лучше. Остальные значения — в
  [таблице размеров точек](put-on-paper.md#dot-size).
- Сохраняйте в PNG или TIFF. Приложение принимает также BMP, PGM/PPM и JPEG.
  JPEG сжимает с потерями и подходит плохо. Не сохраняйте страницы одним PDF.
- Протрите стекло сканера и плотно прижмите страницу: если крышка не прижимает
  бумагу, остаются размытые места.

К скану, сделанному со слишком низким разрешением, добавляется замечание с
нужным разрешением. Это только совет: скан с низким разрешением, который
удаётся прочитать, всё равно используется, а тот, который не может прочитать
обычный метод чтения, передаётся
[второму, более медленному методу чтения](slower-reader.md).

## В приложении { #in-the-application }

Откройте вкладку «Прочитать с бумаги» и добавьте сканы страниц («+ Добавить
сканы…» или перетащите файлы или папки на вкладку).

Программа сама выясняет, какая страница на каждом скане, какая это бумага и
как страница повёрнута. Поэтому сканы можно добавлять в любом порядке, вверх
ногами или повёрнутыми набок. Размер точек и защиту она тоже определяет сама:
настраивать ничего не нужно.

![Сканы читаются, у каждого свой индикатор выполнения и этап](img/being-read.png)

В списке для каждой страницы есть строка с её состоянием. Если выбрать
строку, показывается скан, на котором выделены повреждённые места: колесо мыши
меняет масштаб, перетаскивание сдвигает изображение, двойной щелчок вписывает
страницу целиком.

Когда строка внизу сообщает, что файл проверен, кнопка «Сохранить файл…»
записывает его.

В списке можно:

- убрать скан;
- заменить скан страницы или использовать вместо текущего запасной скан этой
  страницы;
- перейти к другому документу, если добавленные сканы относятся к нескольким
  распечаткам;
- вручную указать страницу для скана, который не удалось опознать;
- собрать документ вручную, если не опознан ни один скан: вы указываете
  бумагу и число страниц, а затем для каждого скана указываете его страницу.

## Пока скан читается { #while-a-scan-is-being-read }

Каждый добавленный скан, пока он не прочитан, стоит в списке под заголовком
«Читаются» вместе с индикатором выполнения и этапом, на котором он находится:

| Этап | Что происходит |
|---|---|
| В очереди | Скан ждёт своей очереди. |
| Открытие файла | Загружается изображение. |
| Поиск страницы | Программа ищет контур страницы. |
| Опознание страницы | Она перебирает бумагу, размер точек и ориентацию, пока что-нибудь не подойдёт. |
| Чтение данных | Точки читаются и корректируются. |
| Медленный метод: выборка, затем «проход 4 из 5» | Только для скана, за который берётся [медленный метод](slower-reader.md). |

Индикатор считает этапы, а не секунды: он может задержаться на одном этапе и
потом прыгнуть вперёд, но никогда не идёт назад. Кнопка «Убрать» прекращает
чтение скана. Прочитанный скан становится своей страницей или попадает в
список как нечитаемый.

## Состояния страниц { #page-states }

| Состояние | Что это значит | Что делать |
|---|---|---|
| В порядке | Страница прочитана, и исправлять не пришлось ни одной ошибки. | Ничего. |
| Исправлена · N | N блоков были повреждены, и коррекция ошибок их исправила. Данные целы. | Ничего. |
| Повреждена · потеряно N | N блоков исправить не удалось, поэтому в сохранённом файле в этих местах неверные данные. | Отсканируйте страницу заново в оттенках серого с разрешением для её размера точек и замените скан. |
| Прочитана медленным методом | Разрешение скана слишком низкое для обычного метода. См. [Сканы со слишком низким разрешением](slower-reader.md). | Убедитесь, что документ проходит проверку. |
| Не читается | Скан не удалось опознать: например, на изображении нет страницы optar или не удалось прочитать надпись. | Отсканируйте его заново или укажите для него страницу вручную. |
| Отсутствует | Скан этой страницы не добавлен. | Добавьте его. В документе с защитой может хватить и остальных страниц, и тогда строка внизу об этом сообщит. |

Если скан, сделанный с разрешением ниже 400 dpi, не читается, об этом
говорится прямо, например: «Скан сделан примерно при 200 dpi, это слишком
низкое разрешение для чтения», — и указывается, какое разрешение нужно для
каждого размера точек.

## Строка внизу { #the-bar-at-the-bottom }

Строка показывает состояние всего документа.

| Что написано в строке | Что это значит |
|---|---|
| Файл восстановлен и проверен · N байт | Все страницы прочитаны, и восстановленный файл совпадает с отпечатком на бумаге. |
| Не совпадает с отпечатком на бумаге | Все страницы прочитаны, но файл не совпадает с исходным, потому что часть данных декодирована неверно. Отсканируйте страницы заново, начиная с тех, что в состоянии «Исправлена». |
| Восстановимо: нет страницы 3, её можно восстановить по остальным | Документ с защитой: страниц не хватает, но прочитанных страниц должно хватить, чтобы их восстановить. |
| Восстановимо: нет страницы 3, восстановлена по остальным · совпадает с отпечатком | Восстановление выполнено и сверено с отпечатком. Дальше указаны размер и что было исправлено. |
| Обработка… Прочитано сканов: 3 из 6 | Сканы ещё читаются. Если у документа уже есть состояние, счётчик стоит после него: «Файл восстановлен и проверен · N байт · Прочитано сканов: 3 из 6». |
| Сверка с отпечатком… | Сверка идёт в фоне. |
| Прочитаны все страницы: N · проверить нельзя (нет метки) | Страницы сделаны старой программой, и отпечатка на них нет. |
| 4 из 6 страниц в порядке · 1 повреждена · 1 отсутствует | В остальных случаях — подсчёт. |

Для документа с защитой окно также показывает, сколько байт исправила защита
и какую часть своего ресурса исправления израсходовало худшее место,
например: «в худшем месте израсходовано 57% ресурса исправления (18 из 32):
умеренный запас». Если исправить не удаётся, окно называет страницы, которые нужно добавить или
отсканировать заново.

!!! info "Что значит «проверен»"
    «Проверен» всегда означает, что отпечаток восстановленного файла совпал с
    отпечатком на бумаге. Это никогда не означает лишь то, что исправление
    прошло без сообщений о сбое.

## Сохранение { #saving }

Если файл не проверен, «Сохранить файл…» просит подтверждения и сообщает, что
с файлом не так.

Документ с защитой, который не удалось исправить, всё же можно сохранить в
том виде, в каком его удалось восстановить, — после предупреждения, что файл
может содержать неверные части. Это возможно, только если прочитана хотя бы
половина его страниц: если меньше, ничего не сохраняется.

## Распечатки старых программ { #printouts-from-old-programs }

На распечатках optar 0.1.0 и программы на C в надписи нет метки. Приложение
их читает, но:

- оно не может определить, относятся ли страницы к одному документу и полон
  ли файл;
- оно не может проверить файл;
- сохранённый файл дополнен нулями до целой страницы.

Сохраняйте такой файл, только прочитав предупреждение, которое показывает
приложение.
