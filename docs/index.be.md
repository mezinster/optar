# optar { #optar }

optar захоўвае файл на паперы. Ён друкуе файл на лазерным прынтары 600 dpi у
выглядзе старонак з дробных чорных і белых кропак, а потым чытае файл назад са
сканаў гэтых старонак.

![Праграма пасля чытання дзвюх старонак: абедзве ў парадку, файл правераны](img/verified.png)

- **На адну старонку A4 змяшчаецца каля 200 000 байтаў** пры стандартным
  памеры кропак.
- **Можна выбраць большыя кропкі**, каб хапіла сканера на 200 dpi; тады на
  старонку змяшчаецца менш.
- **Абарона ад пашкоджанняў** — гэта дадатковыя даныя, размеркаваныя па ўсіх
  старонках. З ёй праграма выпраўляе плямы і адарваныя куткі, а ў дастаткова
  доўгім дакуменце аднаўляе страчаную старонку.
- **Адбітак** файла друкуецца разам з ім. Адноўлены файл называецца
  правераным, толькі калі ён супадае з гэтым адбіткам.

Праграм дзве, і код у іх агульны:

- `optar-gui` — праграма з акном для Linux, macOS і Windows;
- `optar` — праграма для каманднага радка.

## Коратка { #in-short }

1. У праграме адкрыйце ўкладку «Запісаць на паперу», выберыце файл і
   стварыце PDF.
2. Надрукуйце PDF у натуральную велічыню (100%), а не «Па памеры старонкі»,
   на лазерным прынтары 600 dpi.
3. Каб атрымаць файл назад, адскануйце старонкі ў адценнях шэрага ў PNG або
   TIFF з раздзяляльнасцю, патрэбнай для памеру кропак (600 dpi для
   стандартных кропак).
4. Адкрыйце ўкладку «Прачытаць з паперы», дадайце сканы ў любым парадку і
   захавайце файл, калі радок унізе паведаміць, што ён правераны.

## Адкуль ён узяўся { #where-it-comes-from }

optar напісаў на C Карэл «Clock» Кулгаві (Karel Kulhavy) з Twibright Labs у
2007 годзе. Гэты праект — версія на Python, якая чытае і запісвае тыя самыя
старонкі і дадае праграму з акном, большыя кропкі, абарону і адбітак.
Падрабязней — у раздзеле [«Гісторыя»](history.md).
