# ფაილის უკან წაკითხვა { #read-it-back }

## სკანირება { #scanning }

- დაასკანერეთ ნაცრისფერ ტონებში (256 დონე) ან ფერადად. ნუ დაასკანერებთ
  შავ-თეთრად.
- გამორთეთ ნებისმიერი „დოკუმენტის“ რეჟიმი ან ტექსტის გასუფთავება. ის
  წერტილებს შავად ან თეთრად აქცევს, სანამ პროგრამა მათ დაინახავს.
- გამოიყენეთ წერტილის ზომის შესაბამისი გარჩევადობა: სტანდარტული
  წერტილებისთვის 600 dpi, თუმცა 1200 dpi ოდნავ უკეთესია. დანარჩენი მოცემულია
  [წერტილის ზომების ცხრილში](put-on-paper.md#dot-size).
- შეინახეთ PNG ან TIFF ფორმატში. აპლიკაცია ასევე იღებს BMP, PGM/PPM და JPEG
  ფაილებს. JPEG დანაკარგიანი ფორმატია და ცუდი არჩევანია. ნუ შეინახავთ
  გვერდებს ერთ PDF-ად.
- გაწმინდეთ სკანერის მინა და გვერდი ბრტყლად დააჭირეთ: სახურავი, რომელიც
  ქაღალდს არ აჭერს, ბუნდოვან ლაქებს ტოვებს.

ზედმეტად დაბალი გარჩევადობით გაკეთებულ სკანს ერთვის შენიშვნა, რომელშიც
საჭირო გარჩევადობაა მითითებული. ეს მხოლოდ რჩევაა: დაბალი გარჩევადობის სკანი,
რომლის წაკითხვაც შესაძლებელია, მაინც გამოიყენება, ხოლო ის, რომელსაც წაკითხვის
ჩვეულებრივი მეთოდი ვერ კითხულობს, გადაეცემა
[წაკითხვის მეორე, უფრო ნელ მეთოდს](slower-reader.md).

## აპლიკაციაში { #in-the-application }

გახსენით ჩანართი „ქაღალდიდან წაკითხვა“ და დაამატეთ გვერდების სკანები
(„+ სკანების დამატება…“ ან ფაილების თუ საქაღალდეების ჩანართზე გადმოტანა).

პროგრამა თავად არკვევს, რომელი გვერდია თითოეული სკანი, რომელი ქაღალდია და
როგორ არის მობრუნებული. ამიტომ სკანები შეგიძლიათ დაამატოთ ნებისმიერი
თანმიმდევრობით, თავდაყირა ან გვერდულად მობრუნებულიც. ის ასევე თავად ადგენს
წერტილის ზომას და დაცვას; არაფრის მითითება არ არის საჭირო.

![იკითხება სკანები, თითოეულს აქვს პროგრესის ზოლი და მიმდინარე ეტაპი](img/being-read.png)

სიაში თითოეულ გვერდს თავისი სტრიქონი და მდგომარეობა აქვს. სტრიქონის
არჩევისას ჩანს სკანი, რომელზეც დაზიანებული ადგილები მონიშნულია: მასშტაბი
იცვლება თაგვის ბორბლით, გადაადგილება — გადათრევით, ორმაგი დაწკაპუნება კი
გვერდს მთლიანად ათავსებს ფანჯარაში.

როცა ქვედა ზოლში ეწერება, რომ ფაილი შემოწმებულია, „ფაილის შენახვა…“ მას
ჩაწერს.

სიიდან შეგიძლიათ:

- ამოიღოთ სკანი;
- შეცვალოთ გვერდის სკანი ან გამოყენებულის ნაცვლად ამ გვერდის სათადარიგო სკანი
  გამოიყენოთ;
- გადახვიდეთ სხვა დოკუმენტზე, თუ დამატებული სკანები ერთზე მეტ ამონაბეჭდს
  ეკუთვნის;
- სკანს, რომლის ამოცნობაც ვერ მოხერხდა, გვერდი ხელით მიუთითოთ;
- დოკუმენტი ხელით ააწყოთ, როცა ვერცერთი სკანის ამოცნობა ვერ ხერხდება:
  მიუთითებთ ქაღალდს და გვერდების რაოდენობას, შემდეგ კი თითოეულ სკანს მის
  გვერდს მიუთითებთ.

## როცა სკანი იკითხება { #while-a-scan-is-being-read }

ყოველი დამატებული სკანი, სანამ არ წაიკითხება, ჩამოთვლილია სექციაში
„იკითხება“, პროგრესის ზოლითა და იმ ეტაპით, რომელზეც იმყოფება:

| ეტაპი | რა ხდება |
|---|---|
| რიგში | სკანი თავის რიგს ელოდება. |
| ფაილის გახსნა | გამოსახულება იტვირთება. |
| გვერდის ძებნა | პროგრამა ეძებს გვერდის კონტურს. |
| გვერდის ამოცნობა | ის სათითაოდ ცდის ყოველ ქაღალდს, წერტილის ზომასა და ორიენტაციას, სანამ ერთ-ერთი არ მოერგება. |
| მონაცემების წაკითხვა | წერტილები იკითხება და სწორდება. |
| ნელი მეთოდი: ნიმუშების აღება, შემდეგ „გავლა 4 5-დან“ | მხოლოდ იმ სკანისთვის, რომელსაც [ნელი მეთოდი](slower-reader.md) კითხულობს. |

ზოლი ეტაპებს ითვლის და არა წამებს: ის შეიძლება ერთ ეტაპზე გაჩერდეს და შემდეგ
წინ გადახტეს, მაგრამ უკან არასოდეს ბრუნდება. „ამოღება“ სკანის კითხვას
წყვეტს. წაკითხვის შემდეგ სკანი თავის გვერდად იქცევა ან ჩამოთვლილია, როგორც
„ვერ იკითხება“.

| ზოლში წერია | მნიშვნელობა |

დაცვით შექმნილი დოკუმენტისთვის ფანჯარა ასევე აჩვენებს, რამდენი ბაიტი გამოასწორა დაცვამ
და გამოსწორების რესურსის რა ნაწილი გამოიყენა ყველაზე უარესმა ადგილმა,
მაგალითად: „ყველაზე უარესმა ადგილმა გამოსწორების რესურსის 57% გამოიყენა
(32-დან 18): ზომიერი მარაგი“.
თუ გამოსწორება ვერ მოხერხდა, ფანჯარა
ასახელებს გვერდებს, რომლებიც უნდა დაამატოთ ან ხელახლა დაასკანეროთ.

!!! info "რას ნიშნავს „შემოწმებული“"
    „შემოწმებული“ ყოველთვის ნიშნავს, რომ აღდგენილი ფაილის ანაბეჭდი დაემთხვა
    ქაღალდზე დაბეჭდილს. ის არასოდეს ნიშნავს მხოლოდ იმას, რომ გამოსწორებისას
    შეცდომა არ გამოვლენილა.

## შენახვა { #saving }

„ფაილის შენახვა…“, თუ ფაილი შემოწმებული არ არის, გკითხავთ, მაინც შეინახოთ
თუ არა, და გეტყვით, რა არის მასში არასწორი.

დაცვით შექმნილი დოკუმენტი, რომლის გამოსწორებაც ვერ მოხერხდა, მაინც შეგიძლიათ
