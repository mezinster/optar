# optar { #optar }

optar зберігає файл на папері. Програма друкує файл на лазерному принтері з
роздільною здатністю 600 dpi у вигляді сторінок, укритих дрібними чорними й
білими точками, і зчитує файл назад зі сканів цих сторінок.

![Застосунок після зчитування двох сторінок: обидві справні, файл перевірено](img/verified.png)

- **Одна сторінка A4 вміщує близько 200 000 байтів** зі стандартним розміром
  точок.
- **Більші точки** можна вибрати, щоб вистачило сканера з роздільною здатністю
  200 dpi; тоді на сторінці вміщується менше.
- **Захист** — це додаткові дані, рознесені по всіх сторінках. З ним програма
  виправляє плями й відірвані кути, а в достатньо довгому документі відновлює
  втрачену сторінку.
- **Відбиток** файлу друкується разом із ним. Відновлений файл називають
  перевіреним, лише коли він збігається з цим відбитком.

Є дві програми, які використовують той самий код:

- `optar-gui`, настільний застосунок для Linux, macOS і Windows;
- `optar`, програма для командного рядка.

## Коротко { #in-short }

1. У застосунку відкрийте вкладку «Записати на папір», виберіть файл і
   створіть PDF.
2. Надрукуйте PDF на лазерному принтері з роздільною здатністю 600 dpi у
   фактичному розмірі (100%), а не «За розміром сторінки».
3. Щоб отримати файл назад, відскануйте сторінки у відтінках сірого у формат
   PNG або TIFF з роздільною здатністю, яка відповідає розміру точок
   (600 dpi для стандартних точок).
4. Відкрийте вкладку «Зчитати з паперу», додайте скани в будь-якому порядку й
   збережіть файл, коли рядок унизу повідомить, що його перевірено.

## Звідки це взялося { #where-it-comes-from }

optar написав мовою C Карел «Clock» Кулгави з Twibright Labs у 2007 році.
Цей проєкт — версія мовою Python, яка зчитує й записує ті самі сторінки, а
також додає настільний застосунок, більші точки, захист і відбиток. Див.
розділ [Історія](history.md).
