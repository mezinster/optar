# Встановлення { #install }

## Завантаження { #download }

Завантажте файл для своєї системи з
[розділу Releases](https://github.com/mezinster/optar/releases/latest).
`<tag>` нижче означає версію, наприклад `v0.5.0`.

| Система | Настільний застосунок | Командний рядок |
|---|---|---|
| Linux | `optar-gui-<tag>-linux-x86_64` | `optar-<tag>-linux-x86_64` |
| macOS (Apple silicon) | `optar-gui-<tag>-macos-arm64.zip` | `optar-<tag>-macos-arm64` |
| Windows | `optar-gui-<tag>-windows-x86_64.exe` | `optar-<tag>-windows-x86_64.exe` |

Кожна програма — це один файл, і більше нічого встановлювати не потрібно.

- **Linux:** спершу виконайте для файлу `chmod +x`.
- **macOS:** виконайте `chmod +x` для файлу програми командного рядка.
  Розпакуйте застосунок і спробуйте його відкрити. Програми не підписані, тож
  macOS може відмовитися їх запускати: відкрийте «Системні параметри»,
  «Приватність і безпека» й виберіть «Усе одно відкрити» (у старіших версіях
  macOS клацніть застосунок правою кнопкою миші й виберіть «Відкрити»).
- **Windows:** програми не підписані, тож під час першого запуску Windows
  може показати попередження.

## З вихідного коду { #from-source }

Потрібен Python 3.12 або новіший і копія репозиторію.

Програма командного рядка (установлює numpy і Pillow):

    pip install .

Разом із настільним застосунком:

    pip install '.[gui]'
    optar-gui

## Чи все працює { #check-that-it-works }

`optar --version` і `optar-gui --version` виводять версію.

`optar-gui --self-test` запускає застосунок без екрана й з’ясовує, чи може
він закодувати й зчитати сторінки.
