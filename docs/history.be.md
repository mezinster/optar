# Гісторыя { #history }

optar напісаў на C Карэл «Clock» Кулгаві (Karel Kulhavy) з Twibright Labs у
2007 годзе ў выглядзе праграм `optar`, `unoptar` і `pgm2ps`. Яго сайт —
[ronja.twibright.com/optar](http://ronja.twibright.com/optar/). Колін Дзін
(Colin Dean) захоўваў зыходны код даступным і ўдасканальваў яго з 2012 па
2018 год на [github.com/colindean/optar](https://github.com/colindean/optar).

Гэты праект пачаўся з таго зыходнага кода. Першапачатковыя праграмы на C
захоўваюцца без змен у папцы `lega-c` рэпазіторыя. Яны — гісторыя: у гэтым
праекце больш нішто іх не збірае і не запускае.
[README](https://github.com/mezinster/optar#history-the-original-c-program)
захоўвае іх першапачатковыя інструкцыі.

## Версіі гэтага праекта { #versions-of-this-project }

| Версія | Што яна дадала |
|---|---|
| 0.1.0 | Каманду `optar` на Python, якая чытае і запісвае тыя самыя старонкі, што і праграмы на C. |
| 0.2.0 | Праграму з акном і пазнаку ў надпісе з памерам і адбіткам файла. |
| 0.3.0 | Большыя кропкі, абарону і старонкі, якія апазнаюць сябе па сваіх даных. |
| 0.4.0 | Павольны метад чытання для сканаў з занадта нізкай раздзяляльнасцю. |
| 0.5.0 | Індыкатары выканання для сканаў, якія чытаюцца, і падлік таго, што скарэкціраваў павольны метад. |

Сам фармат, у тым ліку тое, што прыйшло з праграмы на C, апісаны ў частцы 8
[спецыфікацыі фармату](format.md).
