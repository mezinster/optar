# Камандны радок { #command-line }

Каманда `optar` закадоўвае файл у старонкі і раскадоўвае сканы назад. Ёй не
патрэбныя ні кампілятар C, ні libpng, ні ImageMagick.

    optar encode INPUT [-o BASE] [--paper a4|letter] [--to pdf|png|pgm] [--label TEXT] [--no-tag]
                 [--dots standard|medium|big|large|xlarge] [--protect none|standard|high]
                 [--compatible] [--format STRING]
    optar decode BASE [-o OUTPUT] [--paper a4|letter] [--format STRING] [--debug-images] [--force]
                 [--no-slow-reader]
    optar --version

## encode { #encode }

Па змаўчанні `encode` запісвае `BASE.pdf` (`BASE` па змаўчанні — `optar_out`),
а з `--to` — старонкі `BASE_0001.png` (або `.pgm`), `BASE_0002.png`, ...

| Вы задаяце | Вы атрымліваеце |
|---|---|
| ні `--dots`, ні `--protect`, або `--compatible` | раздрукоўку, якую чытаюць версія 0.2.0 і праграма на C: стандартныя кропкі, без абароны |
| толькі `--dots X` | гэты памер кропак са стандартнай абаронай |
| толькі `--protect LEVEL` | стандартныя кропкі з гэтай абаронай |
| `--protect none` | без абароны |

Любы з трох апошніх варыянтаў дае самаапазнавальныя старонкі (старонкі, якія
самі паведамляюць, да якога дакумента яны належаць і які ў іх нумар); каб іх
прачытаць, патрэбны optar 0.3 або навейшы. Напрыклад:

    optar encode photo.jpg -o photo --dots large --protect high

Памеры кропак і ўзроўні абароны апісаны ў раздзеле
[«Запісаць файл на паперу»](put-on-paper.md#dot-size).

Сумяшчальная раздрукоўка нясе [пазнаку](identification.md#the-tag) на кожнай
старонцы; каб яе не было, дадайце `--no-tag`.

Па змаўчанні `--paper` — A4.

## decode { #decode }

`decode` чытае `BASE_0001.png`, `BASE_0002.png`, ... і запісвае даныя ў
`-o OUTPUT` або ў stdout. Ён чытае толькі файлы з такімі назвамі.

Што ён робіць, залежыць ад раздрукоўкі. Ён вырашае гэта па першых трох
сканах: калі ніводны з іх не ўдаецца апазнаць як самаапазнавальную старонку,
ён лічыць увесь набор раздрукоўкай версіі 0.2.0 або больш ранняй.

### Самаапазнавальныя старонкі { #self-identifying-pages }

`decode` сам высвятляе па сканах, што на іх.

- Ён прымае сканы ў любым парадку і ў любой арыентацыі.
- Скан, які ён не можа прачытаць, лічыцца адсутнай старонкай.
- Скан, які звычайны метад чытання не можа апазнаць, спачатку перадаецца
  [павольнаму метаду](slower-reader.md), калі вы не задалі `--no-slow-reader`.
- Ён выпраўляе даныя, абразае іх да сапраўднага памеру і звярае з адбіткам.
- Ён запісвае файл, толькі калі той супадае з адбіткам, — хіба што вы задалі
  `--force`: тады захоўваецца тое, што ўдалося аднавіць, нават калі файл не
  прайшоў праверку. Нават з `--force` нічога не захоўваецца, калі прачытана
  менш за палову старонак.

### Раздрукоўкі версіі 0.2.0 і больш ранніх { #printouts-from-020-or-earlier }

- `--paper` павінен быць такім самым, як пры закадаванні.
- Старонка павінна быць у прамым становішчы (кніжная арыентацыя, надпіс
  унізе). Сканы ў альбомнай арыентацыі тут не падтрымліваюцца — гэта
  атрымана ў спадчыну ад дэкодара на C. Праграма з акном прымае любую
  арыентацыю для любой раздрукоўкі.
- `decode` не абразае вынік да памеру з пазнакі і не звярае яго з адбіткам:
  вынік заўсёды дапоўнены нулямі да цэлай старонкі. Праграма з акном робіць
  і тое, і другое. Калі для вашых даных гэта важна, спакуйце іх з дапамогай
  tar.
- `--force` нічога не мяняе, і `decode` пра гэта паведамляе.

## Код выхаду { #exit-status }

| Код | Што азначае |
|---|---|
| 0 | Поспех. Для самаапазнавальных старонак: файл правераны. |
| 1 | Даныя раскадаваны, але выправіць іх нельга, або ў нумарацыі старонак ёсць пропуск, або (для самаапазнавальных старонак) файл не прайшоў праверку. |
| 2 | Памылка выкарыстання або ўваходных даных. |

## Карэкцыйны код { #the-error-correcting-code }

Па змаўчанні выкарыстоўваецца код Голея 24/12. Падтрымліваюцца таксама коды
Хэмінга парадку ад 2 да 5; яны выбіраюцца праз `--format` (шостае поле радка
фармату). Радок фармату вызначаны ў [спецыфікацыі фармату](format.md).
