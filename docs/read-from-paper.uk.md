# Отримати файл назад { #read-it-back }

## Сканування { #scanning }

- Скануйте у відтінках сірого (256 рівнів) або в кольорі. Не скануйте в
  чорно-білому режимі.
- Вимкніть будь-який режим «документ» і будь-яке очищення тексту. Вони
  роблять точки чорними або білими ще до того, як їх побачить програма.
- Вибирайте роздільну здатність за розміром точок: 600 dpi для стандартних
  точок, а 1200 dpi — трохи краще. Решту наведено в
  [таблиці розмірів точок](put-on-paper.md#dot-size).
- Зберігайте у форматі PNG або TIFF. Застосунок також приймає BMP, PGM/PPM і
  JPEG. JPEG стискає із втратами, і це поганий вибір. Не зберігайте сторінки
  одним PDF.
- Почистьте скло сканера й щільно притисніть сторінку: якщо кришка не
  притискає папір, лишаються розмиті місця.

До скану, зробленого з надто низькою роздільною здатністю, додається
примітка, у якій названо потрібну роздільну здатність. Це лише порада: скан із
низькою роздільною здатністю, який вдається зчитати, однаково
використовується, а скан, якого не може зчитати звичайний метод зчитування,
передається
[другому, повільнішому методу зчитування](slower-reader.md).

## У застосунку { #in-the-application }

Відкрийте вкладку «Зчитати з паперу» й додайте скани сторінок («+ Додати
скани…» або перетягніть файли чи теки на вкладку).

Програма сама з’ясовує, яка сторінка на кожному скані, який це папір і як
сторінка повернута. Тож скани можна додавати в будь-якому порядку, догори
ногами або повернутими набік. Розмір точок і захист програма теж визначає
сама; налаштовувати нічого не потрібно.

![Скани зчитуються, у кожного свій індикатор виконання й етап](img/being-read.png)

У списку для кожної сторінки є рядок із її станом. Якщо вибрати рядок, буде
показано скан, на якому позначено пошкоджені місця: коліщатко миші змінює
масштаб, перетягування зсуває зображення, подвійне клацання вміщує всю
сторінку.

Коли рядок унизу повідомить, що файл перевірено, його можна записати кнопкою
«Зберегти файл…».

У списку можна:

- прибрати скан;
- замінити скан сторінки або взяти замість поточного скану запасний скан
  цієї сторінки;
- перейти до іншого документа, якщо додані скани належать до кількох
  роздруківок;
- вручну вказати сторінку для скану, який не вдалося розпізнати;
- зібрати документ вручну, коли не вдається розпізнати жоден скан: ви
  вказуєте папір і кількість сторінок, а потім — сторінку для кожного скану.

## Поки скан зчитується { #while-a-scan-is-being-read }

Кожен доданий скан, доки його не зчитано, показано в групі «Зчитуються» з
індикатором виконання й етапом, на якому він перебуває:

| Етап | Що відбувається |
|---|---|
| У черзі | Скан чекає своєї черги. |
| Відкриття файлу | Завантажується зображення. |
| Пошук сторінки | Програма шукає контур сторінки. |
| Розпізнавання сторінки | Програма пробує кожен папір, розмір точок і положення, доки щось не підійде. |
| Зчитування даних | Точки зчитуються й коригуються. |
| «Повільний метод: вибірка», потім «Повільний метод: прохід 4 з 5» | Лише для скану, за який береться [повільний метод](slower-reader.md). |

Індикатор рахує етапи, а не секунди: він може затриматися на якомусь етапі, а
потім стрибнути вперед, але назад не рухається ніколи. «Прибрати» зупиняє
зчитування скану. Після зчитування скан займає рядок своєї сторінки або
потрапляє до групи «Не зчитуються».

## Стани сторінок { #page-states }

| Стан | Що це означає | Що робити |
|---|---|---|
| Справна | Сторінку зчитано без жодної помилки, яку треба було б виправляти. | Нічого. |
| Виправлена · N | N блоків було пошкоджено, і корекція помилок їх виправила. Дані цілі. | Нічого. |
| Пошкоджена · втрачено N | N блоків не вдалося виправити, тож у збереженому файлі там неправильні дані. | Повторно відскануйте сторінку у відтінках сірого з роздільною здатністю для її розміру точок і замініть скан. |
| Зчитана повільним методом | Роздільна здатність скану була надто низькою для звичайного методу. Див. [Скани з надто низькою роздільною здатністю](slower-reader.md). | Переконайтеся, що документ проходить перевірку. |
| Не зчитується | Скан не вдалося розпізнати: наприклад, на зображенні немає сторінки optar або не вдалося зчитати напис. | Повторно відскануйте сторінку або вручну вкажіть для скану сторінку. |
| Відсутня | Скан цієї сторінки не додано. | Додайте його. У документі із захистом решти сторінок може вистачити, і тоді рядок унизу про це повідомить. |

Скан, зроблений з роздільною здатністю нижче 400 dpi, який не вдається
зчитати, повідомляє про це, наприклад: «Скан зроблено з роздільною здатністю
приблизно 200 dpi, а це надто мало для зчитування», і називає роздільну
здатність, потрібну для кожного розміру точок.

## Рядок унизу { #the-bar-at-the-bottom }

Рядок унизу показує стан усього документа.

| У рядку написано | Що це означає |
|---|---|
| Файл відновлено й перевірено · N байтів | Усі сторінки зчитано, і відновлений файл збігається з відбитком на папері. |
| Не збігається з відбитком на папері | Усі сторінки зчитано, але файл не є оригіналом, бо частину даних декодовано неправильно. Повторно відскануйте сторінки, почавши з позначених як «Виправлена». |
| Відновлення можливе: немає сторінки 3, її можна відновити з решти | Документ із захистом: деяких сторінок немає, але зчитаних сторінок має вистачити, щоб їх відновити. |
| Відновлення можливе: немає сторінки 3, її відновлено з решти · збігається з відбитком | Це відновлення виконано й звірено з відбитком. Далі йдуть розмір і те, що зробило відновлення. |
| Обробка… Зчитано сканів: 3 з 6 | Скани ще зчитуються. Якщо документ уже має стан, який можна показати, лічильник іде після нього: «Файл відновлено й перевірено · N байтів · зчитано сканів: 3 з 6». |
| Звіряння з відбитком… | Звіряння триває у фоновому режимі. |
| Зчитано всі сторінки: N · перевірити не можна (немає мітки) | Сторінки створено старою програмою, і відбитка на них немає. |
| Справних сторінок: 4 з 6 · 1 пошкоджена · 1 відсутня | В інших випадках — лічильник. |

Для документа із захистом вікно також показує, скільки байтів виправив захист
і яку частку свого ресурсу виправлення використало найгірше місце, наприклад:
«у найгіршому місці використано 57% ресурсу виправлення (18 з 32): помірний
запас».
Якщо виправити не вдалося, вікно
називає сторінки, які треба додати або повторно відсканувати.

!!! info "Що означає «перевірено»"
    «Перевірено» завжди означає, що відбиток відновленого файлу збігся з
    відбитком на папері. Це ніколи не означає лише те, що виправлення
    завершилося без повідомлень про невдачу.

## Збереження { #saving }

Якщо файл не перевірено, «Зберегти файл…» просить підтвердження й пояснює,
що з файлом не так.

Документ із захистом, який не вдалося виправити, усе одно можна зберегти в
тому обсязі, у якому його відновлено, після попередження, що у файлі можуть
бути неправильні частини. Це можливо, лише якщо зчитано щонайменше половину
сторінок: якщо менше, нічого не зберігається.

## Роздруківки старих програм { #printouts-from-old-programs }

Роздруківки optar 0.1.0 або програми на C не мають мітки в написі.
Застосунок їх зчитує, але:

- він не може визначити, чи належать сторінки до одного документа і чи файл
  повний;
- він не може перевірити файл;
- збережений файл доповнено нулями до цілої сторінки.

Зберігайте такий файл, лише прочитавши застереження, яке показує застосунок.
