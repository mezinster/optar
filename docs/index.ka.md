# optar { #optar }

optar ფაილს ქაღალდზე ინახავს. ის ფაილს 600 dpi გარჩევადობის ლაზერულ
პრინტერზე ბეჭდავს პატარა შავი და თეთრი წერტილებისგან შედგენილი გვერდების
სახით, შემდეგ კი ამ გვერდების სკანებიდან ფაილს უკან კითხულობს.

![აპლიკაცია ორი გვერდის წაკითხვის შემდეგ: ორივე წესრიგშია, ფაილი შემოწმებულია](img/verified.png)

- **ერთ A4 გვერდზე ეტევა დაახლოებით 200 000 ბაიტი** სტანდარტული წერტილის
  ზომით.
- **შეგიძლიათ აირჩიოთ უფრო მსხვილი წერტილები**, რომ 200 dpi სკანერიც
  საკმარისი იყოს; ამ შემთხვევაში გვერდზე ნაკლები ეტევა.
- **დაზიანებისგან დაცვა** არის დამატებითი მონაცემები, რომლებიც ყველა
  გვერდზეა განაწილებული. მისი წყალობით პროგრამა ასწორებს ლაქებით და
  მოგლეჯილი კუთხეებით გამოწვეულ დაზიანებას, საკმარისად გრძელ დოკუმენტში კი დაკარგულ გვერდსაც
  აღადგენს.
- **ფაილის ანაბეჭდი** იბეჭდება ფაილთან ერთად. აღდგენილ ფაილს შემოწმებული
  ეწოდება მხოლოდ მაშინ, როცა ის ამ ანაბეჭდს ემთხვევა.

არსებობს ორი პროგრამა, რომლებიც ერთსა და იმავე კოდს იყენებს:

- `optar-gui` — სამაგიდო აპლიკაცია Linux-ის, macOS-ისა და Windows-ისთვის;
- `optar` — ბრძანების სტრიქონის პროგრამა.

## მოკლედ { #in-short }

1. აპლიკაციაში გახსენით „ქაღალდზე ჩაწერა“, აირჩიეთ ფაილი და შექმენით PDF.
2. დაბეჭდეთ PDF რეალური ზომით (100%) და არა „გვერდზე მორგებით“, 600 dpi
   გარჩევადობის ლაზერულ პრინტერზე.
3. ფაილის დასაბრუნებლად დაასკანერეთ გვერდები ნაცრისფერ ტონებში, PNG ან TIFF
   ფორმატში, წერტილის ზომის შესაბამისი გარჩევადობით (სტანდარტული
   წერტილებისთვის — 600 dpi).
4. გახსენით „ქაღალდიდან წაკითხვა“, დაამატეთ სკანები ნებისმიერი
   თანმიმდევრობით და შეინახეთ ფაილი, როცა ქვედა ზოლში ეწერება, რომ ის
   შემოწმებულია.

## საიდან მოდის { #where-it-comes-from }

optar 2007 წელს C ენაზე დაწერა კარელ „Clock“ კულჰავიმ (Twibright Labs).
ეს პროექტი Python-ზე დაწერილი ვერსიაა, რომელიც იმავე გვერდებს კითხულობს და
წერს, და ამატებს სამაგიდო აპლიკაციას, უფრო მსხვილ წერტილებს, დაცვას და
ფაილის ანაბეჭდს. იხ. [ისტორია](history.md).
