# История { #history }

optar написал на C Карел «Clock» Кулгави (Karel Kulhavy) из Twibright Labs в
2007 году — это были программы `optar`, `unoptar` и `pgm2ps`. Сайт программы —
[ronja.twibright.com/optar](http://ronja.twibright.com/optar/). Колин Дин
(Colin Dean) с 2012 по 2018 год сохранял исходный код в открытом доступе и
улучшал его на [github.com/colindean/optar](https://github.com/colindean/optar).

Этот проект вырос из того исходного кода. Первоначальные программы на C
хранятся без изменений в папке `lega-c` репозитория. Это история: в этом
проекте их больше ничто не собирает и не запускает. В
[README](https://github.com/mezinster/optar#history-the-original-c-program)
сохранены их первоначальные инструкции.

## Версии этого проекта { #versions-of-this-project }

| Версия | Что добавилось |
|---|---|
| 0.1.0 | Команда `optar` на Python, которая читает и пишет те же страницы, что и программы на C. |
| 0.2.0 | Настольное приложение и метка в надписи с размером и отпечатком файла. |
| 0.3.0 | Более крупные точки, защита и страницы, которые опознаются по своим данным. |
| 0.4.0 | Медленный метод для сканов со слишком низким разрешением. |
| 0.5.0 | Индикаторы выполнения для читаемых сканов и подсчёт того, что скорректировал медленный метод. |

Сам формат, включая то, что пришло из программы на C, описан в части 8
[спецификации формата](format.md).
