# Атрымаць файл назад { #read-it-back }

## Сканаванне { #scanning }

- Скануйце ў адценнях шэрага (256 узроўняў) або ў каляровым рэжыме. Не
  скануйце ў чорна-белым рэжыме.
- Адключыце ўсялякую ачыстку «дакумента» або тэксту. Яна робіць кропкі
  чорнымі або белымі яшчэ да таго, як іх убачыць праграма.
- Выкарыстоўвайце раздзяляльнасць, патрэбную для памеру кропак: 600 dpi для
  стандартных кропак (1200 dpi крыху лепш). Астатнія значэнні — у
  [табліцы памераў кропак](put-on-paper.md#dot-size).
- Захоўвайце ў PNG або TIFF. Праграма прымае таксама BMP, PGM/PPM і JPEG. JPEG
  сціскае са стратамі і дрэнна падыходзіць. Не захоўвайце старонкі адным PDF.
- Пачысціце шкло сканера і прыцісніце старонку роўна: калі вечка не
  прыціскае паперу, застаюцца размытыя плямы.

Да скана, зробленага з занадта нізкай раздзяляльнасцю, дадаецца заўвага з
раздзяляльнасцю, якую варта выкарыстаць. Гэта толькі парада: скан з нізкай
раздзяляльнасцю, які ўдаецца прачытаць, усё роўна выкарыстоўваецца, а той,
што звычайны метад чытання прачытаць не можа, перадаецца
[другому, больш павольнаму метаду чытання](slower-reader.md).

## У праграме { #in-the-application }

Адкрыйце ўкладку «Прачытаць з паперы» і дадайце сканы старонак («+ Дадаць
сканы…» або перацягніце файлы ці папкі на ўкладку).

Праграма сама высвятляе, якая старонка на кожным скане, якая папера і як
старонка павернута. Таму сканы можна дадаваць у любым парадку, дагары нагамі
або павернутымі набок. Яна таксама сама вызначае памер кропак і абарону;
наладжваць нічога не трэба.

![Сканы чытаюцца, у кожнага свой індыкатар выканання і этап](img/being-read.png)

У спісе для кожнай старонкі ёсць адзін радок з яе станам. Калі выбраць
радок, паказваецца скан з вылучанымі пашкоджанымі месцамі: колам мышы яго
можна павялічваць і памяншаць, перацягваннем — пасунуць, а падвойнай пстрычкай — паказаць
старонку цалкам.

Калі радок унізе паведамляе, што файл правераны, кнопка «Захаваць файл…»
запісвае яго.

Са спісу можна:

- прыбраць скан;
- замяніць скан старонкі або ўзяць замест бягучага запасны скан гэтай
  старонкі;
- перайсці да іншага дакумента, калі дададзеныя сканы належаць больш чым да
  адной раздрукоўкі;
- указаць уручную старонку для скана, які не ўдалося апазнаць;
- сабраць дакумент уручную, калі ніводны скан не ўдаецца апазнаць: вы
  ўказваеце паперу і колькасць старонак, а потым — старонку для кожнага скана.

## Пакуль скан чытаецца { #while-a-scan-is-being-read }

Кожны дададзены скан паказваецца ў групе «Чытаюцца», пакуль яго не
прачытаюць, з індыкатарам выканання і этапам, на якім ён знаходзіцца:

| Этап | Што адбываецца |
|---|---|
| У чарзе | Скан чакае сваёй чаргі. |
| Адкрыццё файла | Выява загружаецца. |
| Пошук старонкі | Праграма шукае контур старонкі. |
| Апазнанне старонкі | Яна перабірае паперы, памеры кропак і арыентацыі, пакуль нешта не падыдзе. |
| Чытанне даных | Кропкі чытаюцца і карэкціруюцца. |
| Павольны метад: выбарка, потым «Павольны метад: праход 4 з 5» | Толькі для скана, які бярэ на сябе [павольны метад](slower-reader.md). |

Індыкатар лічыць этапы, а не секунды: ён можа спыніцца на нейкім этапе, а
потым скокнуць, але ніколі не вяртаецца назад. Кнопка «Прыбраць» спыняе
чытанне скана. Калі скан прачытаны, ён становіцца сваёй старонкай або
трапляе ў спіс як скан, які не чытаецца.

## Станы старонак { #page-states }

| Стан | Што азначае | Што рабіць |
|---|---|---|
| У парадку | Старонка прачытана без памылак, якія трэба было б карэкціраваць. | Нічога. |
| Выпраўлена · N | N блокаў былі пашкоджаны, і карэкцыя памылак іх выправіла. Даныя цэлыя. | Нічога. |
| Пашкоджана · страчана N | N блокаў не ўдалося выправіць, таму ў захаваным файле ў гэтым месцы няправільныя даныя. | Адскануйце старонку нанова ў адценнях шэрага з раздзяляльнасцю для яе памеру кропак і замяніце скан. |
| Прачытана павольным метадам | Раздзяляльнасць скана была занадта нізкая для звычайнага метаду. Глядзіце [«Сканы з занадта нізкай раздзяляльнасцю»](slower-reader.md). | Пераканайцеся, што дакумент праходзіць праверку. |
| Не чытаецца | Скан не ўдалося апазнаць: напрыклад, на выяве няма старонкі optar або не ўдалося прачытаць надпіс. | Адскануйце яго нанова або ўкажыце для яго старонку ўручную. |
| Адсутнічае | Скан гэтай старонкі не дададзены. | Дадайце яго. У дакуменце з абаронай астатніх старонак можа і хапіць, і тады радок унізе пра гэта паведаміць. |

Калі скан, зроблены з раздзяляльнасцю ніжэй за 400 dpi, не ўдаецца прачытаць,
праграма так і паведамляе, напрыклад: «Скан зроблены прыкладна пры 200 dpi,
гэта занадта нізкая раздзяляльнасць для чытання», і называе раздзяляльнасць,
патрэбную для кожнага памеру кропак.

## Радок унізе { #the-bar-at-the-bottom }

Радок унізе паказвае стан усяго дакумента.

| Што паведамляе радок | Што азначае |
|---|---|
| Файл адноўлены і правераны · N байтаў | Усе старонкі прачытаны, і адноўлены файл супадае з адбіткам на паперы. |
| Не супадае з адбіткам на паперы | Усе старонкі прачытаны, але гэта не арыгінальны файл, бо частка даных раскадавана няправільна. Адскануйце старонкі нанова, пачынаючы з тых, што маюць стан «Выпраўлена». |
| Аднаўленне магчымае: няма старонкі 3, яе можна аднавіць па астатніх | Дакумент з абаронай: некаторых старонак няма, але прачытаных старонак павінна хапіць, каб іх аднавіць. |
| Аднаўленне магчымае: няма старонкі 3, яна адноўлена па астатніх · супадае з адбіткам | Гэта аднаўленне выканана, і файл звераны з адбіткам. Далей ідуць памер і тое, што было выпраўлена. |
| Апрацоўка… Прачытана сканаў: 3 з 6 | Сканы яшчэ чытаюцца. Калі ў дакумента ўжо ёсць стан, лічыльнік ідзе пасля яго: «Файл адноўлены і правераны · N байтаў · Прачытана сканаў: 3 з 6». |
| Звярка з адбіткам… | Звярка ідзе ў фоне. |
| Прачытаны ўсе старонкі: N · праверыць нельга (няма пазнакі) | Старонкі зроблены старой праграмай, і адбітка на іх няма. |
| 4 з 6 старонак у парадку · 1 пашкоджана · 1 адсутнічае | У астатніх выпадках — падлік. |

Для дакумента з абаронай акно паказвае таксама, колькі байтаў выправіла
абарона і якую долю свайго рэсурсу выпраўлення выкарыстала найгоршае месца,
напрыклад: «у найгоршым месцы выкарыстана 57% рэсурсу выпраўлення (18 з 32):
умераны запас». Калі выправіць не ўдаецца, праграма
называе старонкі, якія трэба дадаць або адсканаваць нанова.

!!! info "Што азначае «правераны»"
    «Правераны» заўсёды азначае, што адбітак адноўленага файла супаў з
    адбіткам на паперы. Гэта ніколі не азначае толькі тое, што выпраўленне
    прайшло без паведамленняў пра збой.

## Захаванне { #saving }

Калі файл не правераны, кнопка «Захаваць файл…» просіць пацвердзіць
захаванне і паведамляе, што з файлам не так.

Дакумент з абаронай, які не ўдалося выправіць, усё роўна можна захаваць у
той меры, у якой ён адноўлены, пасля папярэджання, што ў файле могуць быць
няправільныя часткі. Гэта магчыма, толькі калі прачытана не менш за палову
яго старонак: калі менш, нічога не захоўваецца.

## Раздрукоўкі старых праграм { #printouts-from-old-programs }

На раздрукоўках optar 0.1.0 або праграмы на C у надпісе няма пазнакі.
Праграма іх чытае, але:

- яна не можа ўстанавіць, ці належаць старонкі да адной раздрукоўкі і ці
  поўны файл;
- яна не можа праверыць файл;
- захаваны файл дапаўняецца нулямі да цэлай старонкі.

Захоўвайце такі файл толькі пасля таго, як прачытаеце перасцярогу, якую
паказвае праграма.
