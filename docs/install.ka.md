# ინსტალაცია { #install }

## ჩამოტვირთვა { #download }

ჩამოტვირთეთ თქვენი სისტემის ფაილი
[Releases განყოფილებიდან](https://github.com/mezinster/optar/releases/latest).
ქვემოთ `<tag>` ვერსიას აღნიშნავს, მაგალითად `v0.5.0`.

| სისტემა | სამაგიდო აპლიკაცია | ბრძანების სტრიქონი |
|---|---|---|
| Linux | `optar-gui-<tag>-linux-x86_64` | `optar-<tag>-linux-x86_64` |
| macOS (Apple silicon) | `optar-gui-<tag>-macos-arm64.zip` | `optar-<tag>-macos-arm64` |
| Windows | `optar-gui-<tag>-windows-x86_64.exe` | `optar-<tag>-windows-x86_64.exe` |

თითოეული მათგანი ერთი ფაილია და სხვა არაფრის დაყენებას არ საჭიროებს.

- **Linux:** ჯერ ფაილზე გაუშვით `chmod +x`.
- **macOS:** ბრძანების სტრიქონის ფაილზე გაუშვით `chmod +x`. ამოაარქივეთ
  აპლიკაცია და სცადეთ მისი გახსნა. პროგრამებს ციფრული ხელმოწერა არ აქვს,
  ამიტომ macOS-მა შეიძლება მათი გახსნა არ დაუშვას: გახსენით System Settings
  (სისტემის პარამეტრები), შემდეგ Privacy & Security (კონფიდენციალურობა და
  უსაფრთხოება) და აირჩიეთ „Open Anyway“ („მაინც გახსნა“). macOS-ის ძველ
  ვერსიებში დააწკაპუნეთ აპლიკაციაზე თაგვის მარჯვენა ღილაკით და აირჩიეთ Open
  (გახსნა).
- **Windows:** პროგრამებს ციფრული ხელმოწერა არ აქვს, ამიტომ პირველი
  გაშვებისას Windows-მა შეიძლება გაფრთხილება აჩვენოს.

## საწყისი კოდიდან { #from-source }

საჭიროა Python 3.12 ან უფრო ახალი და რეპოზიტორიის ასლი.

ბრძანების სტრიქონის პროგრამა (აყენებს numpy-სა და Pillow-ს):

    pip install .

სამაგიდო აპლიკაციაც:

    pip install '.[gui]'
    optar-gui

## როგორ დავრწმუნდეთ, რომ მუშაობს { #check-that-it-works }

`optar --version` და `optar-gui --version` ვერსიას აჩვენებს.

`optar-gui --self-test` აპლიკაციას ეკრანის გარეშე უშვებს და ასინჯავს,
შეუძლია თუ არა მას გვერდების კოდირება და წაკითხვა.
