# Як розпізнається сторінка { #how-a-page-identifies-itself }

Програма має знати для кожного скану, до якого документа він належить і яка
це сторінка. Сторінка може повідомити про це двома способами, залежно від
того, як зроблено роздруківку.

| Роздруківка | Як розпізнається |
|---|---|
| Зроблена із захистом або з будь-яким розміром точок, крім стандартного | за заголовком у даних сторінки («сторінки із самоідентифікацією») |
| Сумісна роздруківка версії 0.2.0 або новішої | за міткою в написі внизу |
| Створена версією 0.1.0 або програмою на C | лише за написом, якого немає з чим звірити |

Дійсна мітка в написі завжди має перевагу: сторінка, напис якої містить
дійсну мітку, зчитується як сторінка версії 0.2.0, хоч би що було в її даних.

## Сторінки із самоідентифікацією { #self-identifying-pages }

Сторінки роздруківки, зробленої із захистом або з будь-яким розміром точок,
крім стандартного, несуть відомості про документ у своїх даних: до якої
роздруківки вони належать, свій номер, кількість сторінок, розмір файлу та
його відбиток.

Напис, надрукований унизу, призначений для людей, і для розпізнавання
сторінок його не використовують. У PDF він друкується одним розміром за
будь-якого розміру точок (розміром напису сторінки зі стандартними точками),
щоб умістився весь рядок. Тоді він надто дрібний, щоб його можна було зчитати
зі скану з низькою роздільною здатністю, і вікно показує «(без назви)», доки
файл не буде відновлено й не стане відома його власна назва. Сторінки PNG і
PGM мають один піксель на точку, тож їхній напис намальовано точками сторінки,
і він більшає разом із ними.

Місце, якого такий документ не використовує, заповнено сталим візерунком,
схожим на дані, щоб кожна сторінка друкувалася рівномірно. Версія 0.3.0
заповнювала його нулями, і вони друкувалися білими смугами поперек сторінок.
Зчитуються обидва варіанти, зокрема й версією 0.3.0: жодна програма зчитування
не дивиться на заповнення.

Заголовку сторінки самому по собі не можна довіряти: одна відсканована
сторінка може заявляти, що належить до будь-якого документа. Перевіреним
відновлений файл робить лише його відбиток.

## Напис { #the-label }

Кожна сторінка має внизу напис: формат сторінки, номер сторінки й кількість
сторінок, а далі довільний текст. Для роздруківок версії 0.2.0 і раніших
застосунок зчитує цей напис зі скану.

- Напис із міткою приймається, коли він зчитується правдоподібно, контрольне
  значення мітки відповідає номеру сторінки й кількості сторінок, а розмір
  файлу в мітці узгоджується з цією кількістю сторінок.
- Напис без мітки (роздруківки, зроблені версією 0.1.0 або програмою на C)
  немає з чим звірити, тож його приймають, лише коли він зчитується чітко.
- Напис, схожий на мітку з одним пошкодженим знаком, відхиляється.

Відхилений скан показано в списку як «Не зчитується» із причиною, і ви
можете вручну вказати для нього сторінку.

## Мітка { #the-tag }

Починаючи з версії 0.2.0, `optar encode` і застосунок друкують на початку
довільного тексту кожної сторінки сумісної роздруківки мітку у вигляді
`[SIZE:FINGERPRINT:CC]`.

| Частина | Що означає |
|---|---|
| `SIZE` | розмір файлу в байтах |
| `FINGERPRINT` | перші 8 шістнадцяткових цифр SHA-256 файлу |
| `CC` | контрольне значення з двох шістнадцяткових цифр, яке залежить від номера сторінки й кількості сторінок |

Мітка дає застосунку змогу:

- не плутати сторінки різних роздруківок;
- відхилити напис із міткою, розмір у якій не узгоджується з кількістю
  сторінок;
- відхилити скан, напис якого зчитано неправильно, замість того щоб
  поставити його не на ту сторінку (приблизно 1 помилкове зчитування з 256
  все ж може пройти контроль);
- обрізати відновлений файл до справжнього розміру, щоб у ньому не було
  доповнення нулями;
- порівняти відновлений файл із відбитком: це остаточний контроль того, що
  файл є оригіналом.

Щоб друкувати без мітки, використовуйте `optar encode --no-tag`. Сторінки, які
розпізнаються за своїми даними, мітки не друкують.

Точні визначення наведено в [специфікації формату](format.md): у частині 3
для мітки й у частині 4 для документів із самоідентифікацією.
