# Історія { #history }

optar написав мовою C Карел «Clock» Кулгави з Twibright Labs у 2007 році у
вигляді програм `optar`, `unoptar` і `pgm2ps`. Його домашня сторінка —
[ronja.twibright.com/optar](http://ronja.twibright.com/optar/). Колін Дін
зберігав вихідний код доступним і вдосконалював його з 2012 до 2018 року на
[github.com/colindean/optar](https://github.com/colindean/optar).

Цей проєкт почався з того вихідного коду. Оригінальні програми на C
збережено без змін у теці `lega-c` репозиторію. Вони — історія: ніщо в цьому
проєкті їх більше не збирає й не запускає. У
[README](https://github.com/mezinster/optar#history-the-original-c-program)
збережено їхні оригінальні інструкції.

## Версії цього проєкту { #versions-of-this-project }

| Версія | Що додано |
|---|---|
| 0.1.0 | Команду `optar` на Python, яка зчитує й записує ті самі сторінки, що й програми на C. |
| 0.2.0 | Настільний застосунок і мітку в написі з розміром і відбитком файлу. |
| 0.3.0 | Більші точки, захист і сторінки, які розпізнаються за своїми даними. |
| 0.4.0 | Повільний метод для сканів із надто низькою роздільною здатністю. |
| 0.5.0 | Індикатори виконання для сканів, що зчитуються, і лічильники того, що скоригував повільний метод. |

Сам формат, зокрема те, що походить від програми на C, описано в частині 8
[специфікації формату](format.md).
