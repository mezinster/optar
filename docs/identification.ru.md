# Как опознаётся страница { #how-a-page-identifies-itself }

Программа должна знать для каждого скана, к какому документу он относится и
какая это страница. Страница может сообщить это двумя способами — в
зависимости от того, как была сделана распечатка.

| Распечатка | Чем опознаётся |
|---|---|
| Сделана с защитой или с любым размером точек, кроме стандартного | заголовком в данных страницы («самоопознающиеся страницы»: страницы, которые сами сообщают, к какому документу они относятся и какой у них номер) |
| Совместимая распечатка из 0.2.0 или новее | меткой в надписи внизу |
| Из 0.1.0 или из программы на C | одной только надписью, которую не с чем сверить |

Действительная метка в надписи всегда имеет преимущество: страница, у которой
в надписи есть действительная метка, читается как страница 0.2.0, что бы ни
было в её данных.

## Самоопознающиеся страницы { #self-identifying-pages }

Страницы распечатки, сделанной с защитой или с любым размером точек, кроме
стандартного, несут сведения о документе в своих данных: к какой распечатке
они относятся, свой номер, число страниц, размер файла и его отпечаток.

Надпись, напечатанная внизу, предназначена для людей, и для опознания
страниц она не используется. В PDF она печатается одного размера при любом
размере точек (такого же, как надпись стандартной страницы), чтобы вся
строка поместилась. Поэтому со скана с низким разрешением её не прочитать, и
окно показывает «(без имени)», пока файл не восстановлен и не стало известно
его собственное имя. В страницах PNG и PGM на точку приходится один пиксель,
поэтому надпись на них нарисована точками страницы и растёт вместе с ними.

Место, которое такой документ не использует, заполнено постоянным узором,
похожим на данные, чтобы каждая страница печаталась равномерно. Версия 0.3.0
заполняла его нулями, и они печатались белыми полосами поперёк страниц.
Читаются оба варианта, в том числе версией 0.3.0: ни одна программа чтения не
смотрит на заполнение.

Заголовку страницы самому по себе доверять нельзя: одна отсканированная
страница могла бы заявить, что относится к любому документу. Проверенным
восстановленный файл делает только отпечаток.

## Надпись { #the-label }

Внизу каждой страницы есть надпись: формат страницы, номер страницы и число
страниц, затем произвольный текст. Для распечаток 0.2.0 и более ранних
приложение читает эту надпись со скана.

- Надпись с меткой принимается, если она читается правдоподобно, контрольное
  значение метки совпадает с номером и числом страниц, а размер файла в метке
  согласуется с числом страниц.
- Надпись без метки (распечатки 0.1.0 или программы на C) не с чем сверить,
  поэтому она принимается, только если читается чётко.
- Надпись, похожая на метку с одним повреждённым знаком, отклоняется.

Отклонённый скан попадает в список под заголовком «Не читаются» с указанием
причины, и для него можно указать страницу вручную.

## Метка { #the-tag }

Начиная с 0.2.0, `optar encode` и приложение печатают метку в начале
произвольного текста каждой страницы совместимой распечатки в виде
`[SIZE:FINGERPRINT:CC]`.

| Часть | Что это значит |
|---|---|
| `SIZE` | размер файла в байтах |
| `FINGERPRINT` | первые 8 шестнадцатеричных цифр SHA-256 файла |
| `CC` | контрольное значение из двух шестнадцатеричных цифр, которое зависит от номера страницы и числа страниц |

Метка позволяет приложению:

- не смешивать страницы разных распечаток;
- отклонить надпись с меткой, размер в которой не согласуется с числом
  страниц;
- отклонить скан, надпись которого прочитана неверно, а не поставить его не на
  ту страницу (примерно одно неверное прочтение из 256 всё же может пройти
  контроль);
- обрезать восстановленный файл до настоящего размера, чтобы в нём не было
  дополнения нулями;
- сравнить восстановленный файл с отпечатком — это окончательная проверка
  того, что файл совпадает с исходным.

Чтобы печатать без метки, используйте `optar encode --no-tag`. Страницы,
которые опознаются по своим данным, метку не печатают.

Точные определения — в [спецификации формата](format.md): часть 3 о метке и
часть 4 о самоопознающихся документах.
