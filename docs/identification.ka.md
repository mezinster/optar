# როგორ ამოიცნობა გვერდი { #how-a-page-identifies-itself }

პროგრამამ ყოველი სკანისთვის უნდა იცოდეს, რომელ დოკუმენტს ეკუთვნის ის და
რომელი გვერდია. გვერდს ამის თქმა ორნაირად შეუძლია, იმის მიხედვით, როგორ
შეიქმნა ამონაბეჭდი.

| ამონაბეჭდი | რით ამოიცნობა |
|---|---|
| შექმნილია დაცვით ან ნებისმიერი წერტილის ზომით, სტანდარტულის გარდა | გვერდის მონაცემებში არსებული სათაურით („თვითამოცნობადი გვერდები“, ანუ გვერდები, რომლებიც თავად მიუთითებს, რომელ დოკუმენტს ეკუთვნის და რომელი გვერდია) |
| თავსებადი ამონაბეჭდი, 0.2.0 ან უფრო ახალი ვერსიისა | ქვემოთ დაბეჭდილი წარწერის ჭდით |
| 0.1.0-ით ან C პროგრამით შექმნილი | მხოლოდ წარწერით, რომლის შესადარებელიც არაფერია |

წარწერაში მართებული ჭდე ყოველთვის იმარჯვებს: გვერდი, რომლის წარწერასაც
მართებული ჭდე აქვს, იკითხება როგორც 0.2.0 გვერდი, მიუხედავად იმისა, რას
შეიცავს მისი მონაცემები.

## თვითამოცნობადი გვერდები { #self-identifying-pages }

დაცვით ან ნებისმიერი წერტილის ზომით, სტანდარტულის გარდა, შექმნილი ამონაბეჭდის
გვერდები თავიანთ მონაცემებში ატარებს ცნობებს დოკუმენტის შესახებ: რომელ
ამონაბეჭდს ეკუთვნის, თავის ნომერს, გვერდების რაოდენობას, ფაილის ზომას და
ფაილის ანაბეჭდს.

ქვემოთ დაბეჭდილი წარწერა ადამიანებისთვისაა და გვერდების ამოსაცნობად არ
გამოიყენება. PDF-ში ის ერთი ზომით იბეჭდება, წერტილის ზომის მიუხედავად
(სტანდარტული გვერდის წარწერის ზომით), რომ მთელი სტრიქონი დაეტიოს. ამიტომ ის
ზედმეტად პატარაა დაბალი გარჩევადობის სკანიდან წასაკითხად და ფანჯარა აჩვენებს
„(უსახელო)“, სანამ ფაილი არ აღდგება და მისი საკუთარი სახელი არ გახდება
ცნობილი. PNG და PGM გვერდებს თითო წერტილზე ერთი პიქსელი აქვს, ამიტომ მათი
წარწერა გვერდის წერტილებით იხატება და მათთან ერთად იზრდება.

ადგილი, რომელსაც ასეთი დოკუმენტი არ იყენებს, ივსება ფიქსირებული ნიმუშით,
რომელიც მონაცემებს ჰგავს, ამიტომ ყოველი გვერდი თანაბრად იბეჭდება. 0.3.0
ვერსია ამ ადგილს ნულებით ავსებდა, რაც გვერდებზე თეთრი ზოლების სახით
იბეჭდებოდა. ორივე იკითხება, 0.3.0-ითაც: ვერცერთი წამკითხავი პროგრამა შევსებას
არ უყურებს.

გვერდის სათაური თავისთავად არასანდოა: ერთ დასკანერებულ გვერდს შეუძლია
განაცხადოს, რომ ნებისმიერ დოკუმენტს ეკუთვნის. აღდგენილ ფაილს შემოწმებულად
მხოლოდ მისი ანაბეჭდი აქცევს.

## წარწერა { #the-label }

ყოველ გვერდს ქვემოთ წარწერა აქვს: გვერდის ფორმატი, გვერდის ნომერი და გვერდების
რაოდენობა, შემდეგ თავისუფალი ტექსტი. 0.2.0 და უფრო ადრეული ვერსიების
ამონაბეჭდებისთვის აპლიკაცია ამ წარწერას სკანიდან კითხულობს.

- ჭდიანი წარწერა მიიღება, როცა ის სარწმუნოდ იკითხება, ჭდის საკონტროლო
  მნიშვნელობა ემთხვევა გვერდის ნომერსა და გვერდების რაოდენობას, ხოლო ჭდეში
  მითითებული ფაილის ზომა ამ გვერდების რაოდენობას შეესაბამება.
- ჭდის გარეშე წარწერას (0.1.0-ით ან C პროგრამით შექმნილი ამონაბეჭდები)
  შესადარებელი არაფერი აქვს, ამიტომ ის მიიღება მხოლოდ მაშინ, როცა მკაფიოდ
  იკითხება.
- წარწერა, რომელიც ჭდეს ჰგავს, მაგრამ ერთი დაზიანებული ნიშანი აქვს,
  უარყოფილია.

უარყოფილი სკანი ჩამოთვლილია, როგორც „ვერ იკითხება“, მიზეზის მითითებით, და
შეგიძლიათ მისი გვერდი ხელით მიუთითოთ.

## ჭდე { #the-tag }

0.2.0 ვერსიიდან `optar encode` და აპლიკაცია თავსებადი ამონაბეჭდის ყოველი
გვერდის თავისუფალი ტექსტის დასაწყისში ბეჭდავს ჭდეს, ფორმით
`[SIZE:FINGERPRINT:CC]`.

| ნაწილი | მნიშვნელობა |
|---|---|
| `SIZE` | ფაილის ზომა ბაიტებში |
| `FINGERPRINT` | ფაილის SHA-256-ის პირველი 8 თექვსმეტობითი ციფრი |
| `CC` | ორი თექვსმეტობითი ციფრის საკონტროლო მნიშვნელობა, რომელიც გვერდის ნომერსა და გვერდების რაოდენობაზეა დამოკიდებული |

ჭდე აპლიკაციას საშუალებას აძლევს:

- სხვადასხვა ამონაბეჭდის გვერდები ერთმანეთისგან განასხვაოს;
- უარყოს ჭდიანი წარწერა, რომლის ზომაც გვერდების რაოდენობას არ შეესაბამება;
- უარყოს სკანი, რომლის წარწერაც არასწორად იქნა წაკითხული, ნაცვლად იმისა,
  რომ ის არასწორ გვერდზე მოათავსოს (256 არასწორი წაკითხვიდან დაახლოებით 1
  მაინც შეიძლება გაიაროს საკონტროლო მნიშვნელობასთან შედარება);
- აღდგენილი ფაილი მის ნამდვილ ზომამდე შეკვეცოს, რომ მასში ნულებით შევსება არ
  იყოს;
- აღდგენილი ფაილი ანაბეჭდს შეადაროს, რაც საბოლოო შემოწმებაა იმისა, რომ ფაილი
  თავდაპირველია.

ჭდის გარეშე დასაბეჭდად გამოიყენეთ `optar encode --no-tag`. გვერდები, რომლებიც
თავიანთი მონაცემებით ამოიცნობა, ჭდეს არ ბეჭდავს.

ზუსტი განმარტებები მოცემულია [ფორმატის სპეციფიკაციაში](format.md): მე-3
ნაწილში — ჭდისთვის და მე-4 ნაწილში — თვითამოცნობადი დოკუმენტებისთვის.
