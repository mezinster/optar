# Командная строка { #command-line }

Команда `optar` кодирует файл в страницы и декодирует сканы обратно. Ей не
нужны ни компилятор C, ни libpng, ни ImageMagick.

    optar encode INPUT [-o BASE] [--paper a4|letter] [--to pdf|png|pgm] [--label TEXT] [--no-tag]
                 [--dots standard|medium|big|large|xlarge] [--protect none|standard|high]
                 [--compatible] [--format STRING]
    optar decode BASE [-o OUTPUT] [--paper a4|letter] [--format STRING] [--debug-images] [--force]
                 [--no-slow-reader]
    optar --version

## encode { #encode }

`encode` по умолчанию записывает `BASE.pdf` (по умолчанию `BASE` — это
`optar_out`), а с `--to` — страницы `BASE_0001.png` (или `.pgm`),
`BASE_0002.png`, ...

| Что вы указываете | Что получаете |
|---|---|
| ни `--dots`, ни `--protect`, или `--compatible` | распечатку, которую читают 0.2.0 и программа на C: стандартные точки, без защиты |
| только `--dots X` | этот размер точек со стандартной защитой |
| только `--protect LEVEL` | стандартные точки с этой защитой |
| `--protect none` | без защиты |

Любой из трёх последних вариантов создаёт самоопознающиеся страницы
(страницы, которые сами сообщают, к какому документу они относятся и какой у
них номер); чтобы их прочитать, нужен optar 0.3 или новее. Например:

    optar encode photo.jpg -o photo --dots large --protect high

Размеры точек и уровни защиты описаны в разделе
[«Записать файл на бумагу»](put-on-paper.md#dot-size).

На каждой странице совместимой распечатки есть
[метка](identification.md#the-tag); чтобы её не печатать, добавьте
`--no-tag`.

По умолчанию `--paper` — A4.

## decode { #decode }

`decode` читает `BASE_0001.png`, `BASE_0002.png`, ... и записывает данные в
`-o OUTPUT` или в stdout. Он читает только файлы с такими именами.

Что он делает, зависит от распечатки. Решение принимается по первым трём
сканам: если ни один из них не опознан как самоопознающаяся страница, набор
считается распечаткой 0.2.0 или более ранней версии.

### Самоопознающиеся страницы { #self-identifying-pages }

`decode` сам выясняет по сканам, что это за страницы.

- Он принимает сканы в любом порядке и в любой ориентации.
- Скан, который не удалось прочитать, считается отсутствующей страницей.
- Скан, который не может опознать обычный метод чтения, сначала передаётся
  [медленному методу](slower-reader.md), если не указан `--no-slow-reader`.
- Он исправляет данные, обрезает их до настоящего размера и сверяет с
  отпечатком.
- Файл записывается, только если он совпадает с отпечатком, — если не указан
  `--force`: с ним сохраняется то, что удалось восстановить, даже если файл не
  прошёл проверку. Но и с `--force` ничего не сохраняется, если прочитано
  меньше половины страниц.

### Распечатки 0.2.0 и более ранних версий { #printouts-from-020-or-earlier }

- `--paper` должен быть таким же, как при кодировании.
- Страница должна стоять прямо (книжная ориентация, надпись внизу). Сканы в
  альбомной ориентации здесь не поддерживаются — это унаследовано от декодера
  на C. Настольное приложение принимает любую ориентацию для любой
  распечатки.
- `decode` не обрезает результат до размера из метки и не сверяет его с
  отпечатком: результат всегда дополнен нулями до целой страницы. Настольное
  приложение делает и то, и другое. Если для ваших данных это важно, упакуйте
  их с помощью tar.
- `--force` ничего не меняет, и `decode` об этом сообщает.

## Код возврата { #exit-status }

| Код | Что это значит |
|---|---|
| 0 | Успех. Для самоопознающихся страниц: файл проверен. |
| 1 | Данные декодированы, но содержат ошибки, которые не поддаются коррекции, или в нумерации страниц есть пропуск, или (для самоопознающихся страниц) файл не прошёл проверку. |
| 2 | Ошибка в использовании команды или во входных данных. |

## Корректирующий код { #the-error-correcting-code }

По умолчанию используется код Голея 24/12. Поддерживаются также коды Хэмминга
порядка от 2 до 5; они выбираются через `--format` (шестое поле строки
формата). Строка формата определена в [спецификации формата](format.md).
