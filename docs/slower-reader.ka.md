# ზედმეტად დაბალი გარჩევადობის სკანები: წაკითხვის ნელი მეთოდი { #scans-that-are-too-coarse-the-slower-reader }

0.4.0 ვერსიიდან პროგრამას აქვს წაკითხვის მეორე, უფრო ნელი მეთოდი იმ
სკანებისთვის, რომლებიც მათი წერტილის ზომისთვის ზედმეტად დაბალი გარჩევადობით
არის გაკეთებული, მაგალითად, სტანდარტული წერტილებით დაბეჭდილი გვერდისთვის,
რომელიც 600-ის ნაცვლად 300 dpi გარჩევადობით არის დასკანერებული.

თუ შეგიძლიათ, დაასკანერეთ რეკომენდებული გარჩევადობით. ნელი მეთოდი ზოგიერთ
დაბალი გარჩევადობის სკანს აღადგენს, მაგრამ არა ყველას (იხ.
[„რა არის ნაჩვენები და რა — არა“](evidence.md#the-slower-reader)).

## როდის ეშვება { #when-it-runs }

ის თავისით ეშვება, ორ შემთხვევაში:

- წაკითხვის ჩვეულებრივი მეთოდი სკანს ვერ ამოიცნობს, მაგრამ მასში გვერდის
  კონტურს პოულობს.
- დაბალი გარჩევადობის სკანმა (წერტილზე 2,5-ზე ნაკლები სკანის პიქსელი)
  ჩვეულებრივ მეთოდს მხოლოდ ჭდის გარეშე წარწერა მისცა და თავსართი — არა, ხოლო
  გვერდის მონაცემები ცუდად იკითხებოდა (მისი სიმბოლოების 1% ან მეტი
  შეუსწორებელი იყო). ასეთ სკანზე წარწერა შეიძლება მაინც იკითხებოდეს იქ, სადაც
  მონაცემები არ იკითხება.

გვერდი, რომლის მონაცემებიც კარგად იკითხება, თავსართის გარეშე ძველი გვერდია და
მას ხელი არ ეხება. თუ ნელი მეთოდი ვერაფერს პოულობს, ძალაში რჩება წარწერის
წაკითხვის შედეგი.

## როგორ მუშაობს { #how-it-works }

ნელი მეთოდი სკანს ადიდებს. იმ წერტილებიდან, რომლებშიც ჩვეულებრივი მეთოდი
დარწმუნებულია, ის სწავლობს, როგორ ერწყმის მეზობელი წერტილები ერთმანეთს
გვერდის თითოეულ ნაწილში. შემდეგ ამ ცოდნით კითხულობს ყოველ წერტილს და ყოველ
სიმბოლოს მთლიანად ირჩევს.

## აპლიკაციაში { #in-the-application }

![ნელი მეთოდით წაკითხული ორი გვერდი, შესწორებული წერტილები მონიშნულია](img/slow-pages.png)

*გენერირებული სატესტო გვერდი, პატარა და ძალიან დაბალი გარჩევადობით
დასკანერებული. შესწორებული წერტილები გადახედვაზე მონიშნულია.*

- სანამ ის მუშაობს, სკანის სტრიქონი აჩვენებს ნელი მეთოდის ეტაპს და პროგრესს.
  სტრიქონის არჩევისას ჩანს, რომ ამას დაახლოებით ერთი წუთი სჭირდება.
- შემდეგ სტრიქონში ეწერება, რომ გვერდი წაკითხულია ნელი მეთოდით და რამდენი
  წერტილი შეასწორა მან, მაგალითად: „გვერდი 3 · წაკითხულია ნელი მეთოდით ·
  შესწორდა 265 112 წერტილი“. შესწორებული ეწოდება წერტილს, რომლის საკუთარ
  კვალს მისი სიმბოლოს არჩევისას ანგარიში არ გაეწია.
- შესწორებული წერტილები სკანის გადახედვაზე მონიშნულია, თითოეული ნიშნული ერთი
  წერტილის სიგანისაა. დაბალი გარჩევადობის სკანებზე ეს ხშირად წერტილების
  რამდენიმე პროცენტია, ამიტომ მთლიანად დანახულ გვერდს ისეთივე მკვრივი
  ელფერი ედება, როგორიც შესწორებებია. გადიდებისას ცალკეული წერტილები ჩანს.
- დოკუმენტის შემოწმების შემდეგ სტრიქონს ემატება, გვერდის რამდენი ბაიტი
  გამოასწორა დოკუმენტის დაცვამ („· დოკუმენტის დაცვით გამოსწორდა 6 912
  ბაიტი“). გვერდის არჩევისას ორივე რიცხვი ჩანს.

ასეთ გვერდს არასოდეს ეწოდება „წესრიგშია“ და ქვედა ზოლში ის ცალკე ითვლება.
ნელი მეთოდი ყოველ სიმბოლოს თავის საუკეთესო ვარაუდს ანიჭებს, ამიტომ მას არ
შეუძლია თქვას, რა არის გვერდზე გამოუსწორებელი.

## ბრძანების სტრიქონში { #on-the-command-line }

`optar decode` მასაც თავისით უშვებს და stderr-ში ამას აცნობებს ყოველი
სკანისთვის, რომელზეც ნელ მეთოდს ცდის. `--no-slow-reader` მას თიშავს.

## რამდენ ხანს გრძელდება { #how-long-it-takes }

შემუშავების კომპიუტერზე A4 გვერდს სულ 40-დან 70 წამამდე დასჭირდა: 20–35
წამი, სანამ ჩვეულებრივი მეთოდი დანებდებოდა, შემდეგ კი 20–35 წამი — ნელ
მეთოდს.

გამოსახულება, რომელიც საერთოდ არ არის optar-ის გვერდი, მაგრამ რომელშიც
გვერდის კონტური მოიძებნება, დაახლოებით 20–35 წამით მეტ დროს მოითხოვს, ვიდრე
ნელი მეთოდის გარეშე.

## შეზღუდვები { #limits }

- ის გვერდს მხოლოდ მისი მონაცემების თავსართით ამოიცნობს. ძველი, 0.2-ის
  სტილის გვერდები, რომლებიც წარწერის ჭდით ამოიცნობა, მის ფარგლებში არ
  ხვდება.
- გვერდი, რომლის ჭდეც ჩვეულებრივმა მეთოდმა მიიღო, ნელ მეთოდს არასოდეს
  გადაეცემა.
- მოსალოდნელია, რომ სტანდარტული დაცვა არ იქნება საკმარისი სტანდარტული
  წერტილების გვერდისთვის, რომელიც დაახლოებით 290 dpi გარჩევადობით არის
  დასკანერებული. ერთადერთ რეალურ დოკუმენტს, რომელიც ამ გზით აღდგა, მაღალი
  დაცვა ჰქონდა და იმაზე მეტი გამოსწორება დასჭირდა, ვიდრე სტანდარტულ დაცვას
  შეუძლია.
- ის არასწორ ფაილს სწორ ფაილად არ წარმოაჩენს: როგორც ყოველთვის, ფაილს შემოწმებულად
  მხოლოდ ანაბეჭდი აქცევს.
