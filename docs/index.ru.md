# optar { #optar }

optar хранит файл на бумаге. Он печатает файл на лазерном принтере 600 dpi в
виде страниц из мелких чёрных и белых точек, а затем читает файл обратно со
сканов этих страниц.

![Приложение после чтения двух страниц: обе в порядке, файл проверен](img/verified.png)

- **На одну страницу A4 помещается около 200 000 байт** при стандартном
  размере точек.
- **Можно выбрать более крупные точки**, чтобы хватило сканера на 200 dpi;
  тогда на страницу помещается меньше.
- **Защита от повреждений** — это дополнительные данные, распределённые по
  всем страницам. С ней программа исправляет пятна и оторванные уголки, а в
  достаточно длинном документе восстанавливает потерянную страницу.
- **Отпечаток** файла печатается вместе с ним. Восстановленный файл
  называется проверенным, только если он совпадает с этим отпечатком.

Программ две, и код у них общий:

- `optar-gui` — настольное приложение для Linux, macOS и Windows;
- `optar` — программа для командной строки.

## Коротко { #in-short }

1. В приложении откройте вкладку «Записать на бумагу», выберите файл и
   создайте PDF.
2. Напечатайте PDF в натуральную величину (100%), а не «По размеру страницы»,
   на лазерном принтере 600 dpi.
3. Чтобы получить файл обратно, отсканируйте страницы в оттенках серого в PNG
   или TIFF с разрешением, которое нужно для размера точек (600 dpi для
   стандартных точек).
4. Откройте вкладку «Прочитать с бумаги», добавьте сканы в любом порядке и
   сохраните файл, когда строка внизу сообщит, что он проверен.

## Откуда он взялся { #where-it-comes-from }

optar написал на C Карел «Clock» Кулгави (Karel Kulhavy) из Twibright Labs в
2007 году. Этот проект — версия на Python, которая читает и пишет те же
страницы и добавляет к ним настольное приложение, более крупные точки, защиту
и отпечаток. Подробнее — в разделе [«История»](history.md).
