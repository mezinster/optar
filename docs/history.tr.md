# Tarihçe { #history }

optar, 2007'de Twibright Labs'ten Karel 'Clock' Kulhavy tarafından C ile
`optar`, `unoptar` ve `pgm2ps` programları olarak yazıldı. Ana sayfası
[ronja.twibright.com/optar](http://ronja.twibright.com/optar/) adresindedir.
Colin Dean, 2012'den 2018'e kadar kaynak kodu erişilebilir tuttu ve
[github.com/colindean/optar](https://github.com/colindean/optar) adresinde
geliştirdi.

Bu proje o kaynak koddan yola çıktı. C ile yazılmış özgün programlar,
deponun `lega-c` klasöründe değiştirilmeden saklanır. Bunlar artık tarihtir:
bu projede hiçbir şey onları derlemez ya da çalıştırmaz.
[README](https://github.com/mezinster/optar#history-the-original-c-program)
dosyası onların özgün talimatlarını saklar.

## Bu projenin sürümleri { #versions-of-this-project }

| Sürüm | Ne ekledi |
|---|---|
| 0.1.0 | C programlarıyla aynı sayfaları okuyup yazan Python `optar` komutu. |
| 0.2.0 | Masaüstü uygulaması ve etikette dosyanın boyutunu ve parmak izini taşıyan künye. |
| 0.3.0 | Daha büyük noktalar, koruma ve kendini verilerinden tanıtan sayfalar. |
| 0.4.0 | Çözünürlüğü çok düşük taramalar için yavaş okuma yöntemi. |
| 0.5.0 | Okunmakta olan taramalar için ilerleme çubukları ve yavaş yöntemin düzelttiklerinin sayıları. |

Biçimin kendisi, C programından gelenler de dâhil olmak üzere,
[biçim belirtiminin](format.md) 8. kısmında açıklanmıştır.
